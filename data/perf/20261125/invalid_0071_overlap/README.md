# 무효: 계획 0071 첫 측정(11/25 22:50–11/26 00:16)
처음 시작한 측정 스크립트를 멈췄는데(작업 중지) 안쪽 bash가 살아남아, 두 번째로 시작한 측정과 **겹쳐서** 돌았다.
- 증거: 100명 시험인데 서버 로그의 로그인이 200–400번(정상 100번)
- 첫 스크립트가 중간에 번호표 수를 바꿔(10·15·12) 두 번째 스크립트의 시험 도중 API 컨테이너가 다시 뜸
- 그래서 이 폴더의 결과는 모두 쓰지 않는다. 원본은 원인 확인용으로만 남김
- 재발 방지: 측정 스크립트가 시작 전에 다른 k6가 돌면 멈추고, 매 시험 전에 번호표 수를 확인. run.sh는 날짜를 시작 때 한 번만 정함(PERF_DATE)
