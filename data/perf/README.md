# 성능 실측 원본

## 우주 루프 맵 아이폰 실측 (2026-11-21, 상준 + Claude, 계획 0063)

- 기기: 상준 아이폰 15(iPhone15,4, A16, 메모리 6GB), iOS 26.6.1. 맥에 USB로 연결한 채(놓인 자세·충전 여부는 기록 안 함), 가로 화면 2556x1179
- 빌드: `feat/space-loop`의 `SpaceLoop` 장면 하나, 메뉴 Scrun → Space Loop → iOS 성능 측정 빌드(개발 빌드, IL2CPP, Xcode Release). 측정 장치 `Scripts/SpaceLoopPerfProbe.cs`
- 품질: 앱과 같은 `ScrunQuality` 자동 단계 → **Medium**(30fps, 렌더 배율 0.85, 그림자 40m, MSAA 4x, 블룸 켬)
- 방법: 5구간 x 3곳(구간 시작 + 100·300·500m)에 순간이동해 10 km/h로 달리며 곳마다 데우기 뒤 기록. 아바타는 v8 + v9 동작 1명(20명 측정은 아래)
- 값: fps·프레임 시간(평균·p95·최대, ms), CPU 메인 스레드·GPU 시간(FrameTimingManager, ms), 그리기 호출·SetPass·삼각형·정점(개발 빌드 카운터), 메모리(MB), 발열(iOS thermalState 0 보통 – 3 매우 뜨거움)

| 파일 | 내용 |
|---|---|
| `spaceloop_iphone15_20261121_medium30.csv` | 앱 설정(30fps)으로 15곳 x 3바퀴(약 6분), 곳마다 데우기 2초 + 기록 6초 |
| `spaceloop_iphone15_20261121_analyze.csv` | ① `60fps`: 상한을 60으로 풀고 15곳(데우기 2초 + 5초) ② `끄기`: 4곳에서 하늘 단색·후처리·반투명(10개)·MSAA·그림자·렌더 배율 0.7을 하나씩(1.5초 + 4초) ③ `20명`: 30fps에서 아바타 20명(내 아바타 + 복제 19명, 앞뒤 2–30m·옆 ±3m)으로 구간마다 1곳 |

주의
- 30fps 상한에서는 아이폰이 GPU 클럭을 낮춰 GPU 시간이 부풀어 보인다(같은 곳이 30fps에서 25–31ms, 60fps에서 15ms). 여유는 `60fps` 줄로 본다. 같은 이유로 `끄기` 비교는 차이가 작게 나온다(하늘 단색만 약 2ms)
- 개발 빌드라 출시 빌드보다 조금 느릴 수 있다. 그리기 호출·삼각형 카운터는 개발 빌드에서만 읽힌다
- 측정 화면의 한 줄 글자(OnGUI)가 그리기 호출을 몇 개 더한다
- 앱의 HUD·실시간 연결·속도 센서는 없는 상태(장면만)다
