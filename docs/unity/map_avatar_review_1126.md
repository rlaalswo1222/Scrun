## 4. 좋은 것

- 아바타 한 명 3,892–5,520 삼각형, 재질 1개, 옷 정점은 뼈 2개 이하. 러닝복을 갈아입어도 그리기 호출이 늘지 않는다.
- 6벌이 뒤(게임 카메라)에서도 서로 구별된다. 셔츠 색·번호표·모자·종아리 슬리브가 다르다.
- 트랙 키트(회색 판 길, 흰 차선, 가드레일)가 다섯 구간 내내 같아서 한 코스로 읽힌다.
- 구름 위 기지와 밤 숲 호수는 볼거리 밀도와 분위기가 좋다.
- 성능은 11/21 아이폰 15 실측(30fps 고정, 그리기 호출 60–110, 아바타 20명 30fps)으로 여유가 있다.

## 5. 다음 순서 제안

1. v10 + v11 달리기를 develop에 넣기, 같이 걷기를 v11 방식으로 새로 만들기(Mixamo 걷기 빼기).
2. 맵 경계 두 곳 고치기: 구름 → 화성 떠 있는 절벽, 달 → 구름 하늘.
3. 내 캐릭터 색 고정(구간 빛 영향 줄이기, 테두리 빛).
4. 얼음·달 구간 중간 거리 볼거리 채우기.

## 6. 다시 하는 법

스크립트는 `art/review_1126/scripts/`에 있다(안의 출력 경로는 그날 임시 폴더라 바꿔서 쓴다).
- 아바타 지표: `Blender -b art/avatar/avatar_work_v11.blend --python avatar_metrics.py`
- 아바타 렌더: `Blender -b art/avatar/avatar_work_v11.blend --python avatar_renders.py`
- 맵 촬영: Unity에서 SpaceLoop 재생 → 일시정지, MCP 서버 켠 뒤 `python3 -I shots.py 60,300,...` (`uc.py`가 MCP 호출, MCP for Unity v10.3.0은 `execute_code`에 `action: "execute"`가 필요)
