# 아이폰 안 실시간 속도 — 첫 시험 (계획 0010)

**예비 실험**: 1명·1회·같은 날 보정. 보정(7, 8, 9, 10 올라가는 순서)과 자유 달리기가 같은 기록이고, 자유 달리기 속도가 거의 보정 범위 안(7에서 9)이라 낙관적일 수 있음.

## 조건 (10/29 04:01, 기록 `data/runs/20261029-040156/`, 메모 `note.md`)
- 피험자 민재(M, 키·몸무게 미기록), 10/29 02:55와 같은 러닝머신. 아이폰 15 계기판 위, 에어팟 프로 3 양쪽, 노트북 없음
- SpeedRecorder "보정 1분 + 자유 달리기"(커밋 7bcc580): 보정 7(25초) → 8, 9, 10(15초) → 자유 달리기 173초. 실제 속도 = 화면 ± 버튼(달리는 본인이 누름)

## 방법 (`speedlab/exp/live_eval.py`)
- 1.5초 안에 연달아 누른 ±는 마지막 값 하나. 실제 속도가 바뀐 뒤 10초는 버림(계획 0010 판정)
- 비교 값은 폰이 실시간으로 낸 `estimate.csv`(0.5초마다) 그대로, PC에서 다시 계산하지 않음
- 폰만(`kmh_phone`)은 걷기로 판단된 동안 값이 없어서 달리기 구간만 비교
