# 계획 0063: 워치 팔 스윙으로 보폭을 가를 수 있는지 (헬스장 기록)

## 맥 할 일 (11/21 헬스장, 민재가 맥·아이폰·워치 들고 감)
1. 도착하면: 아이폰을 꽂고 Xcode로 앱을 한 번 빌드·설치(무료 팀 서명 7일 갱신, 내일 0060 에어팟 실험용)
2. 세트마다 민재 아이폰 Sensor Logger 기록(폰 + 워치)을 AirDrop으로 받으면 바로 확인: 파일·센서 목록(워치 Wrist Motion 포함), 실제 샘플링 빈도(목표 100 Hz 근처), 길이, 끊긴 구간, 시작·끝 점프 3번이 폰·워치 가속도 둘 다에 보이고 시각이 맞는지. 이상하면 그 자리에서 다시 뛰게 알림
3. 민재가 부르는 대로 `data/runs/20261121-watch/note.md`에 실험 메모 적기(아래 "메모" 칸). 원본 zip은 같은 폴더(커밋은 민재가 요청할 때)
4. 첫 세트(6 km/h 1분)만 하고 받아서 워치 데이터가 들어왔는지 먼저 확인 → 들어왔으면 나머지 진행

- 상태: **승인**(2026-11-21 민재, 헬스장 감) · 기록 대기
- 담당: 민재
- 왜: 지금 달리기 속도는 충격 중심이라 세게 밟으면 튀고(0060), 걸음 수가 같은데 속도가 다를 때 가르지 못함. 팔 스윙 폭·주기가 보폭을 알려 주는지 보는 것(가설). 11/14 미팅에서 "워치 팔 스윙 보폭 = 실험 먼저"
- 기기: 상준 애플워치(11/21 **민재 아이폰에 페어링**해 빌림), 민재 아이폰(계기판에 올려놓기). Sensor Logger **"Phone & Watch" 기록**으로 한 세션에 같이(같은 아이폰이라 시각이 거의 맞음, 점프는 검산용). 우리 앱은 아이폰에서 센서 원본을 저장하지 않아 오늘은 안 씀. 에어팟은 11/22에 받음 → 그날 같은 순서로 한 번 더(에어팟 포함)
- Sensor Logger 설정: 워치 Wrist Motion, 아이폰 가속도계·선형 가속도·회전 속도·중력·방향, 빈도 최대. 위치·기압계·자력계 끔(공개 저장소, 모터 자기장)

## 순서
1. Phone & Watch 기록 시작 → **러닝머신 벨트 양옆 발판**(바닥 아님, 폰이 러닝머신 울림으로 느낌)에서 1초 간격 점프 3번(시간 검산)
2. 6 → 8 → 10 → 12 km/h 각 1분(바꾼 시각 메모)
3. **걸음 수 고정**: 메트로놈 170 bpm에 맞춰 8 → 10 → 12 km/h 각 1분. 걸음 수가 같고 속도만 다를 때 워치가 가르는지가 핵심
4. 멈춘 뒤 점프 3번 → 기록 끝
5. (시간 남으면, 따로) Sensor Logger 끄고 워치 기본 운동 앱 "실내 달리기"로 8·10 km/h 각 2분 → 워치에 뜬 페이스를 사진으로. 애플 자체 추정이 얼마나 맞는지 비교 기준(빌린 워치라 실외 보정 안 된 상태)

- 워치에서 같이 볼 것(가설): 팔 스윙 주기 = 걸음 수 이중 확인(에어팟 끊길 때), 손목에 온 착지 충격 시각, 심박(Sensor Logger 워치 칸에 있으면 켬, 속도 튐 검사용). 애플도 실외 달리기 보폭을 팔 움직임으로 추정함(Apple Watch 사용 설명서 "Outdoor Run" 지표, 실내는 보폭·발 닿는 시간·수직 진폭 안 남김 — Apple 개발자 포럼 714484)
