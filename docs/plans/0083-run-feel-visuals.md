## 목표
아바타로 달리는 화면이 힘차고 즐겁게 보이게 한다. 거리·속도·기록 값은 그대로 두고 **보이는 것만** 바꾼다.

## 정한 것 (11/27 상준)
- 카메라는 지금 그대로(뒤 4.6m, 높이 2.2m, 넓게 보이는 쪽이 좋음). 걸음 출렁임·기울기는 멀미 때문에 안 함
- 이어폰 소리는 넣지 않음
- 화면(아바타 동작)과 효과에 집중
- (같은 날) 착지 먼지 같은 입자 효과는 "짜친다, 없는 게 낫다" → 쓰지 않는다. 생동감은 다른 방식으로 올린다

## 할 일
1. **동작 v12 "힘찬 달리기"** (Blender `gait_v11_chibi.py`에서 이어서)
   - 지금 카메라에서도 보이게 크게: 엉덩이 출렁임 4.5cm → 10cm 안팎(화면에서 5px → 12px 이상), 팔 흔들기 30cm → 45cm 이상, 무릎·뒤꿈치 더 높이, 공중 시간 더
   - 빠를수록 더 힘차게: 같은 블렌드 안에서 속도가 올라가면 앞 기울기·팔·무릎이 커지는 "편하게 ↔ 힘껏" 두 판을 섞음. 지금 v11은 6 → 17 km/h에서 출렁임이 오히려 줄어듦
   - 착지 때 살짝 눌리고 뜰 때 늘어나기: Humanoid는 뼈 크기를 옮기지 못하므로 Unity 코드로(아바타 전체 크기를 짧게 바꿈)
   - 걷기도 같은 방식으로 새로 만들어 Mixamo 걷기를 뺀다. 걷기 ↔ 달리기 자세 차이(1° ↔ 11°)도 같이 줄인다
   - 지친 모습은 쓰지 않는다(폐기 개념). 표현은 "힘차게"
2. **입자 없이 생동감 올리기** (후보, 상준이 고름)
   - 아바타 2차 움직임: 번호표·헤어밴드 끈·셔츠 밑단이 착지마다 출렁임(흔들림 뼈). 러닝복 레벨이 높을수록 볼 거리가 많아짐
   - 표정: 달릴 때 힘찬 얼굴(입 벌림·눈에 힘), 빨라지면 더. 지친 얼굴은 쓰지 않는다
   - 맵이 속도에 반응: 길 가장자리 LED가 내 속도에 맞춰 뒤로 흐름, 가드레일 기둥·등을 촘촘하게(가까운 물체가 빨리 지나가 속도감), 구간 문을 지날 때 빛이 훑고 지나감
   - 다른 러너와: 앞지를 때 고개 돌려 보기·손 인사
   - 임팩트 5종도 입자 대신 다른 표현으로 다시 생각(이름·종류가 두 벌이라 [팀 확인]: 서버 예시 `stub_data.py` 발자국 불꽃·바람 꼬리·물결·별 가루·오로라 / Figma·프로토타입 스파크 트레일·바람 자국·불꽃 발자국·별빛 오라·번개 질주, DB 시드 없음)
3. **성능**: 아이폰 15에서 30fps 유지, 늘어나는 그리기 호출 10 이하
