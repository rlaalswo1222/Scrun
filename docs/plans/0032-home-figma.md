## 정할 것
1. **누가**: (가) 민재가 화면 + `/home` 연결, 서버 DB(목표·레벨·홈)는 지환 그대로 **(추천: 0031 주간 목표와 같은 방식, 지환에게 알림)** vs (나) 지환에게 넘기고 민재는 안 함
2. **예시 응답을 어떻게 그릴지**: 지금 `/home`을 그대로 그리면 모든 사람에게 가짜 친구·가짜 2/3회가 보임. (가) `/home`의 코스는 진짜 코스 목록으로, 목표·레벨·친구·기록은 DB 연결 전까지 "없음"(목표 null·Lv.1·친구 0·기록 0 → B-04)으로 바꿈. 서버 한 곳만 고치고 지환이 DB 연결하면 그대로 **(추천: 거짓 정보를 안 보여 줌. 단 지환 영역 파일이라 알림)** vs (나) 예시 그대로 그림(B-01만 보임)
3. **달리는 친구가 없을 때**(Figma에 없는 상태): (가) "지금 달리는 친구가 없어요" + [친구 찾기] → 친구 탭 **(추천: B-04 노트 "친구 추가는 G-05")** vs (나) 칸을 숨김
4. **코스 카드 그림**: Figma는 실사풍 사진·"한강 러닝 코스". 서버 썸네일이 null이라 C-01처럼 하늘색 칸 + 첫 글자 **(추천, 사진은 섬 캡처가 생기면)** vs 섬 캡처를 지금 만들어 넣음
5. **언제**: 홈은 11/13 시연 길목. (가) 오늘 브랜치에서 만들고 시연 뒤 머지 **(추천)** vs (나) 시연 전에 머지
