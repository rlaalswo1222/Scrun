## 하는 것
1. **H-01 마이 메인**: 닉네임·Lv·"인증 마크 N개"·"다음 레벨까지 N km", 누적 거리·인증·레벨 세 칸(`GET /users/me`·`/users/me/progress`), 메뉴(러닝복 → H-04, 속도 재보정 "마지막 보정 MM.DD" → H-09, 설정 → H-10). 이름 줄을 누르면 H-11. 보일 때마다 다시 받음(인증 직후 레벨이 바로 보이게)
2. **H-11 프로필 편집**: 닉네임(가입과 같은 확인·정규화, A-06 코드 재사용)·키·몸무게 → `PATCH /users/me`. 키·몸무게를 바꿨으면 "재보정하기 →" 안내(정할 것 2)
3. **H-04 레벨·러닝복**: 지금 레벨·세트 이름·누적·다음 레벨까지, Lv.1–6 줄(임계값은 서버 `progress`가 주는 값만으로 그림: 지금은 `nextLevelAtM`만 오므로 세트 표는 앱 상수 + 서버 임계값이 바뀌면 같이 바꿀 곳을 한 곳에)
4. **H-09 속도 재보정**: 마지막 보정 날짜·센서 구성(`GET /users/me/calibration`) → "다시 보정하기"로 기존 보정 흐름(`CalibrationIntroScreen`, 계획 0023). 개발용 브랜치 `fix/dev-recalibrate`는 이걸로 대신(지움)
5. **H-10 설정**: 공개 "친구에게 러닝 피드 공개"(`feedShareDefault`, `PATCH /users/me/settings`), 연결 "이어폰"(지금 상태, `Native.Headphones`)·"카카오 계정 연결됨", 데이터 "계기판 사진: 인증 직후 삭제", 약관·개인정보처리방침(`GET /agreements`의 문서 주소), 로그아웃(확인 시트 → `LogoutAsync` → 로그인 화면). 개발 빌드면 맨 아래 "네이티브 점검"
6. 테스트(EditMode: 화면 이름 칸·숫자 글자·로그아웃 흐름·프로필 저장 요청 모양), 에디터 Play 캡처로 Figma와 맞춤, 문서 `unity_map.md`·노션
