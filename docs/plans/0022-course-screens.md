- 기준: 노션 작업 표 "[FE] 코스 목록·상세·맵 입장 화면"(C-01, C-02, I-10, I-11), "[3D] 기존 섬 맵(Island01) 코스 4개 확인·코스 입장 연결", 서버는 계획 0021(PR #30), 앱 구조는 `docs/unity/unity_map.md` "앱 코드 묶음"

## 하는 것
1. **서버 호출**: `Api.Courses`(목록·상세·입장)와 DTO(`Course`, `CourseDetail`, `MapEntry`)를 `App/Api/`에. 썸네일 `null`이면 기본 그림
2. **코스 목록 C-01** `CourseListScreen`: 이름·길이(km)·지금 달리는 사람 수. 누르면 상세. 홈 탭은 아직 빈 자리라(홈은 S6) 홈에 "코스 고르기" 버튼 하나만 둔다
3. **코스 상세 C-02** `CourseDetailScreen`(탭 숨김): 이름·길이·분위기·설명·지금 인원/최대 인원, "맵 입장" 버튼 → `POST /entries`
   - 409 `CALIBRATION_REQUIRED` → "속도 보정이 먼저 필요해요" 안내(보정 화면은 민재 S2, 붙일 자리만)
   - 409 `COURSE_FULL` → I-11 "코스가 가득 찼어요, 다른 코스를 골라 주세요" → 목록으로
   - 네트워크 없음 → I-10(공통 `Feedback`, 다시 시도)
4. **맵 화면** `MapScreen`(가로, 탭 숨김): Island01 씬을 앱 위에 겹쳐 불러오고(additive, 앱 화면·로그인은 그대로 살아 있음), 나가면 내린다. 왼쪽 위 "나가기"
5. **앱 → 섬 씬 이음매**: 앱 코드(`Scrun.App`)는 섬 스크립트를 부를 수 없으므로, 앱이 `MapLaunch`(코스 ID → 도로망 코스 ID `crs_lake_loop` → `lake_loop`, 입장 위치 m)를 남기고 섬 씬의 새 컴포넌트 `MapLaunchApplier`가 시작할 때 읽어 `RouteTrack.SetRoute` → `RunnerController.Teleport` → 봇을 그 근처로. 섬 씬을 혼자 Play하면(앱 없이) 지금처럼 기본 코스
6. **테스트(EditMode)**: 코스 ID → 도로망 코스 ID 변환, DTO 읽기(서버 예시 JSON), 입장 실패 코드별 안내 문구

## 확인
에디터 Play(로컬 서버 + 가짜 로그인): 홈 → 목록(4개, 서버 값) → 상세 → 입장 → 가로 맵에서 고른 코스·입장 위치에 아바타 → 나가기 → 상세. 보정 없는 계정은 보정 안내, 서버가 꺼져 있으면 연결 안내. 코스 4개 각각 들어가 출발점이 맞는지(노션 "완료 확인")

## 하지 않는 것
러닝 설정·거치 안내(S2, 상세 → 맵 사이에 들어감), 보정 화면(민재 S2), 실시간 러너(S3), 썸네일 그림(상준), 화면 모양 다듬기(상준)
