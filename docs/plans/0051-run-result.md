## 흐름
```
인증 완료(E-06 "다음") → E-11 인증 후 반영(GET rewards) ─ 레벨업이면 바가 차고 3초 뒤 → E-13 → "계속하기"
                                                          └ "운동 결과 보기" ───────────────┴→ E-12 결과
미인증(E-08 저장·E-02 포기·D-22 "촬영 없이 마무리"·마감) ────────────────────────────────→ E-14(E-12의 미인증 모양)
E-12·E-14: 닫기·"홈으로" → 홈 탭 / "기록 보기" → F-01(다음 계획 BL-20, 그 전엔 숨김) / 대조 자세히 → E-15 시트
```

## 하는 것
1. `RunResultScreen`(E-12·E-14 한 화면, 기록 ID로 `GET /runs/{id}`): 날짜·인증 칩·거리(미인증은 "km · 센서 값")·시간·평균 페이스·목표, 함께 달린 러너(이름 2명 + "외 N명", 없으면 줄 숨김), 속도 변화 그래프(`speedSeries`, Painter2D, 미니맵과 같은 방식), 피드 공유 토글(`PATCH`, 실패하면 되돌리고 안내), 대조 시트 E-15(계기판 값이 있을 때만 줄 보임). 기록 상세(F-03·F-04, 다음 계획)에서 같은 화면을 다시 씀
2. `RewardsScreen`(E-11, `GET rewards`): 주간 목표 횟수, 레벨 전후·경험치 바(이전 값에서 이후 값으로 차오름), 러닝복 단계 이름, 인증 마크, 임팩트 해금(있을 때만). 레벨업이면 바가 다 찬 뒤 3초에 E-13 덮개(컨페티 없이 반짝임만, 정할 것 2) → "계속하기" → E-12
3. 연결: 코스 상세의 `AfterVerify`·`MapExit.Finished`가 결과로 감(인증 화면이 결과(VERIFIED·UNVERIFIED)를 넘겨줌). 결과 화면이 쌓인 동안 탭바 숨김, 닫으면 결과 화면들을 내리고 홈 탭
4. 순수 계산(EditMode): 경험치 바 비율·"다음 Lv.N까지", 함께 달린 러너 줄, 그래프 점 줄이기, 공유 문구(인증/미인증), 날짜 "11.03 (월) 오전 7:40"(사용자 시간대)
5. 확인: EditMode, 에디터 Play(로컬 8001, 가짜 OCR로 인증 완료 → E-11 → E-13 → E-12, 촬영 없이 마무리 → E-14, 공유 끄고 켜기, 대조 시트). 문서 `unity_map.md`·노션

## 정할 것
1. **기록을 서버에 못 올렸을 때(오프라인 종료, 이 폰에 남음)**: (가) **이 폰의 세션 값으로 E-14 간이 결과(거리·시간·페이스·목표만, 공유·그래프·러너 없이, "연결되면 미인증 기록으로 올라가요") (추천: 끝까지 달렸는데 아무것도 안 보이면 기록이 사라진 줄 앎)** vs (나) 지금처럼 안내창만 띄우고 코스 상세
2. **E-13 레벨업 연출의 러닝복 그림**: 단계별 러닝복 세트 그림이 아직 없음(BL-34 3D, 새 아바타 뒤). (가) **메인 캐릭터 그림(`CharacterRun.png`) 하나 + 단계 이름 글자("기능성 세트"), 반짝임만, 컨페티·아바타 등장은 에셋이 생기면 (추천: 레벨업 자체는 지금 알릴 수 있고, 그림만 나중에 바꾸면 됨)** vs (나) E-13을 빼고 E-11에 "레벨업!" 글자만
3. **"기록 보기"(F-01)**: 다음 계획(BL-20 기록 목록·상세)에서 만듦. (가) **그 전엔 버튼을 숨김 (추천: 오늘·내일 바로 이어서 만듦)** vs (나) 마이 탭으로
