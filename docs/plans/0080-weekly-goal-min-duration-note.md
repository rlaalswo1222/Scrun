# 계획 0080: 주간 목표에 안 들어간 이유 보여 주기 (5분 미만)

- 상태: **초안, 나중에 함**(2026-11-26 민재 "일단 계획만 세우고 넘어가자")
- 담당: 민재
- 왜: 11/26 민재 아이폰에서 인증 완료 기록 둘이 있는데 홈 "이번 주 0/3회"·기록 탭 "인증 0/3". 운영 DB로 확인: 두 기록 계기판 시간 2분 28초·2분 36초 → 주간 목표 1회 = **인증 완료 + 5분 이상**(계획 0054, 서버 `weekly_min_s = 300`)이라 안 셈. 규칙대로지만 앱이 이유를 안 알려 줌
  - 운동 결과 화면은 서버가 `weeklyGoal.counted: false`를 주는데 앱이 안 씀(`Dtos.cs` `Counted`)
  - 기록 탭 셋째 칸 이름 "인증"인데 값은 "목표에 들어간 횟수/목표" → 인증 완료 기록이 보이는데 0이라 헷갈림

## 하는 것
1. 운동 결과 화면: 인증됐지만 `counted`가 false면 한 줄 "5분 넘게 달려야 주간 목표 1회로 세요"(임시, 상준 확인)
2. 기록 탭 셋째 칸 이름: 목표가 있으면 "인증" → "목표"(목표가 없을 땐 인증 완료 횟수라 "인증" 그대로)
3. EditMode: counted false일 때 한 줄, 칸 이름 두 경우

## 판정
- EditMode 통과, 에디터에서 5분 미만 인증 기록 결과 화면, 아이폰(맥 묶음)
