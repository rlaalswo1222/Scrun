# 계획 0050: 고스트러너 — 러닝 설정에서 내 지난 기록을 고르고, 섬에서 반투명 "어제의 나"와 함께 달리기 (BL-24)

- 상태: **승인(11/18 민재: 정할 것 1·2·3 모두 가)** · 구현 중
- 담당: 민재(원래 지환 S7 [FE] 고스트 선택·표시, 11/18 민재가 가져옴). 기록 상세 F-02의 "이 기록으로 고스트 달리기" 버튼은 지환 기록 화면(BL-20) 위라 그때 이 흐름에 연결
- 왜: 서버는 준비됨(`GET /runs/{runId}/ghost` 1초 속도 시계열 #63, `POST /runs`의 `ghostRunId`·`run_ghosts`). 앱은 고를 곳도, 섬에 그릴 것도 없음(섬의 시험용 고스트는 앱에서 들어오면 꺼 둠)
- 근거: 상준 백로그 BL-24 ① 러닝 설정(C-01)에서 고스트 추가 여부 ② "변경"으로 내 과거 기록 중 하나(시트) ③ 반투명 아바타로 나에게만(확정) ④ 진행 차이 배너 ⑤ 기록이 없으면 안내. Figma(11/18 읽음) D-01·D-02 러닝 설정 "고스트러너 · 어제의 나와 함께 달려요. 나에게만 보여요." 카드(켜면 "10.05 (일) · 5.1km · 31:20 · 변경 ›"), D-03 "함께 달릴 내 기록" 시트(날짜·거리·인증 칩·시간·평균 페이스, 선택 완료), D-04 기록 없음("고스트 없이 입장"), D-13 배너 "어제의 나보다 +42m 앞서요"(Figma 노트는 뒤처질 땐 "−Nm" 중립 문구 → 11/18 민재: 뒤처져도 몇 m 뒤인지 분명히), 앞뒤 간격 줄에 "어제의 나"

## 흐름
```
D-06 러닝 설정(RunSetupView) 고스트 카드 켜기 → (정할 것 1) 기록 요약 · "변경 ›" → D-03 시트(GET /runs) / 기록 없으면 D-04
  → 시작 → 고스트 시계열 미리 받기(GET /runs/{id}/ghost) → 3·2·1 끝: 고스트가 내 자리에서 같이 출발
  → 달리는 동안: 고스트 위치 = 기록의 "내가 달린 시간(멈춤 뺌)"에서의 거리, 섬에 반투명 몸(나만), HUD 배너 + 앞뒤 간격 줄 → POST /runs에 ghostRunId
```

## 하는 것
1. 러닝 설정(지환 `RunSetupView`, D-06 자리): 고스트 카드(D-01·D-02), 기록 고르기 시트(D-03, `GET /runs` 최근 순·더 보기), 기록 없음(D-04). 고른 기록은 `RunSetup.GhostRunId` → 센서 준비·카운트다운이 `POST /runs`에 실음
2. 재생: 시계열(1초 칸 속도)을 누적 거리로 바꿔 두고(`GhostTrack` 순수 C#, EditMode), 내 `RunSession` 달린 시간(멈춤 뺌)으로 고스트 거리 → 섬 위치(출발한 자리 + 거리, 한 바퀴 넘으면 이어서)
3. 섬: `AppRunBridge`가 시험용 고스트 몸(`Runner_Ghost` 반투명 재질, `RunnerTag.Kind.Ghost`)을 앱 고스트용으로 다시 켜고 `RunLink.Ghost`가 주는 위치·속도로 움직임(실시간 방에는 안 보냄 → 나에게만)
4. HUD: D-13 배너("어제의 나보다 +42m 앞서요" / 뒤처지면 "어제의 나보다 18m 뒤처져요", 11/18 민재), 앞뒤 간격 줄·이름표에 "어제의 나"
5. 테스트(EditMode: 시계열 → 거리, 멈춤 뺀 시간, 기록 끝 뒤, 배너 문구, 고르기 요청), 에디터 Play(지난 기록 하나로 고스트 켜고 달리기 → 배너·간격이 시계열과 맞는지), 문서 `unity_map.md`·노션

## 정할 것
1. **고스트를 켰을 때 처음 고른 기록**: (가) **가장 최근에 끝난 내 기록을 바로 골라 둠(D-02처럼 요약이 바로 보이고 "변경"으로 바꿈) (추천: Figma D-02가 켜자마자 요약을 보여 주고, 대부분 "어제의 나"를 원함)** vs (나) 시트에서 직접 고를 때까지 비어 있음
2. **미인증 기록도 고스트로**(Figma D-03 노트 "인증 여부 무관 💡" 제안): (가) **모두 고를 수 있고 미인증 칩만 표시 (추천: 내 기록이라 조작 걱정이 없고, 기록이 적은 초기 사용자도 쓸 수 있음)** vs (나) 인증 완료만
3. **고스트 기록이 끝난 뒤**(고스트 거리·시간을 넘음): (가) **고스트는 그 자리에 서 있고 배너는 "어제의 나는 여기까지 달렸어요"(임시) (추천: 갑자기 사라지면 어디로 갔는지 헷갈림)** vs (나) 고스트를 숨기고 배너도 끔
