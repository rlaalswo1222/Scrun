# 계획 0003: SpeedLab 안내 모드 (보정·검증, 버튼 입력 없음)

- 상태: **구현** (2026-10-28). 에디터에서 보정·검증 한 바퀴씩 확인, APK 빌드 완료, 폰 확인 남음
- 바뀐 점: 검증 모드는 맞추는 시간 10초(3 km/h씩 바뀌는 구간), 보정 끝에 충격 기울기가 음수면 경고. 4번(튀는 구간 표시)은 PC 분석에서
- 작성: 2026-10-28
- 근거: [ADR-0005](../adr/0005-guided-calibration.md) 안내형 보정을 SpeedLab에 구현. 같은 방식으로 다른 날 블라인드 검증의 실제 속도 표시도 해결

## 무엇을
1. 모드 두 개
   - 보정: 7, 8, 9, 10, 9.5, 8.5, 7.5 km/h 각 20초
   - 검증: 8, 10, 7, 9, 8.5, 9.5 km/h 각 60초 (계획 0004에서 20초로 줄임)
2. 진행: 화면에 크게 "N km/h로 맞추세요" + 신호음 → 5초 대기(벨트 가속) → 기록 → 다음 속도. 남은 시간 표시
3. 기록: 구간 시작·끝과 안내 속도를 `events.csv`에 자동 기록(`guide_start`, `guide_end`)
4. 실수 대비: 구간 앞 몇 초는 분석에서 버림, 추정값이 구간 안에서 크게 튀면 표시
5. 보정 모드가 끝나면 폰 보정 파일에 바로 저장(지금은 PC 계산 → push)

## 하지 않는 것
- 음성 안내(TTS)는 나중. 지금은 신호음 + 큰 글씨
- 본 앱 반영은 검증 결과를 보고 결정

## 확인
- 에디터에서 안내 진행·events 기록 확인 → APK 빌드 → 폰에서 한 바퀴(짧은 시간 설정으로) 확인
