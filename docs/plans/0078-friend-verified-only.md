- 친구 순위·친구 고스트는 **없음**(고스트는 내 기록만, `runs.py` `ghostRunId는 내 끝난 기록만`)
- 친구 기록이 보이는 곳: **피드**(G-01 `GET /feed`)와 **친구 프로필 최근 기록**(G-09 `GET /friends/{id}`). 둘 다 공유한 끝난 기록 = 인증 대기·인증·미인증(`friends.py` `_visible_runs`), 앱이 "미인증" 마크

## 고른 안: B (11/26 민재)
- 피드(G-01)·친구 프로필 최근 기록(G-09)에서 **인증 완료 기록만 거리·시간·페이스**를 보이고, 인증 대기·미인증 기록은 카드는 그대로 두고 숫자 자리에 "인증한 러닝만 기록이 보여요"(임시, 상준 확인). 칩은 지금대로(인증 완료·미인증, 대기는 없음)
- **앱 화면 규칙으로**(`FriendText`): 서버가 숫자를 null로 주면 지금 깔린 앱이 피드를 못 읽음(`int` 칸) → 서버 응답은 그대로. 나중에 API에서도 빼려면 앱이 null을 받게 먼저 배포한 뒤
- `lastRunAt`(친구 목록 "N시간 전 러닝")은 활동 표시라 그대로
- EditMode: 상태별 숫자 줄·프로필 큰 글자

## 처음 적은 안들
### A (추천했던 안)
- **A. 피드·친구 프로필에 인증 기록만**(서버 `_visible_runs`를 `VERIFIED` + 공유로). 친구 거리·페이스를 나란히 보게 되는 곳이 둘뿐이라 여기서 거름. 인증 대기 기록은 인증되면 그때 피드에 뜸, 미인증은 친구에게 안 보임(내 기록 탭엔 그대로)
  - `lastRunAt`도 같은 조건(보이는 기록과 어긋나지 않게)
  - 앱: 피드·프로필의 "미인증" 마크가 더는 안 쓰임 → 마크 코드는 두되(옛 서버 응답) 문구·빈 상태 확인
  - 서버 테스트: 미인증·대기 기록이 피드·프로필·`lastRunAt`에 안 나옴, 인증되면 나옴. 운영 배포 필요(앱 변경 없이도 바로 적용)
- 다른 안 B. 기록은 다 보이되 미인증·대기는 거리·페이스를 숨기고 "달렸어요"만 → 비교는 막고 활동은 보임. 피드 칸 모양이 둘이 되어 Figma G-01과 달라짐(상준)
- 다른 안 C. 지금대로(마크로 구분) + 문서에 "비교·순위가 생기면 인증만" 원칙만 → 피드백 3순위를 안 한 것
