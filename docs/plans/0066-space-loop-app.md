# 계획 0066: 우주 루프 맵을 앱 러닝 흐름에 연결 + 아이폰 성능 실측

## 맥 할 일 (Windows 구현 끝, 11/21 — `feat/space-loop-app` 머지 뒤 develop에서)
장면만 따로 잰 아이폰 15 실측은 상준 #122(계획 0063)에 있음: 5구간 15곳 모두 30fps, 그리기 호출 60–110, 아바타 20명 112–142, 발열 보통, 60fps 상한에서도 60.1 → **장면 자체는 기준 통과**. 남은 건 앱 안에서
(1·2는 11/23 맥에서 끝: 흐름 통과, 30fps 유지 — 결과는 아래 "진행"의 맥 줄. 2의 20분은 책상 두드리기 17분, 배터리 % 못 잼)
3. 두 번째 아이폰(또는 시뮬레이터)으로 같은 코스 같이 달리기: 다른 러너가 새 아바타로 보이는지
4. 결과를 "진행"에. 통과하면 ADR-0013 승인 제안(그때 섬 코스 4개 끄는 마이그레이션·CLAUDE.md "가상 섬" 문구)

- 상태: **승인** (2026-11-21 민재 "ㄱㄱ") · **Windows 구현·에디터 확인 끝**(11/21) · 아이폰 실측 대기(맥)
- 담당: 민재(앱 연결·서버·실측), 상준(성능이 모자랄 때 맵 줄이기)
- 왜: 11/20 카톡 "맵·아바타가 화면보다 먼저, 상준이 넘기면 민재가 앱에서 실행해 성능 측정". 맵·아바타는 #120·#121로 develop에 들어왔지만 앱은 아직 섬(Island01)만 띄움. 교수님 피드백 "아바타 누락"
- 지금 앱이 맵 씬에서 찾는 것(섬 기준): `RunnerTag`(플레이어·봇·고스트) 19개, `RouteTrack`(섬 도로망, 코스 ID로 경로 고르기), `ScrunQuality`, `GhostRecorder`, `RunnerLabels`, `FollowCamera`. 우주 루프 장면엔 `FollowCamera`·`SplineTrack`만 있음 → 그대로 띄우면 `AppRunBridge`가 "플레이어나 코스를 못 찾음"으로 꺼짐

## 하는 것
1. **코스 → 장면**: `MapLaunch.SceneName` 하나를 코스별로(`crs_space_loop` → `SpaceLoop`, 그 밖 → `Island01`). Build Settings에 `SpaceLoop` 추가
2. **장면 파일은 안 고치고 불러올 때 코드로 붙이기**(상준이 계속 장면을 고치므로, 섬과 같은 방식 `MapLaunchApplier`): 우주 루프가 열리면
   - 장면의 `Runner`에 `RunnerTag`(플레이어)
   - 다른 사람·고스트 몸 원본 = 플레이어 `Runner`(새 아바타 + `AvatarGaitDriver` External) 복제 하나를 꺼 둠, 고스트는 반투명 재질
   - `SpaceLoopDevKeys`·`FakeSpeedSource` 끄기(앱 HUD·진짜 센서가 맡음)
3. **코스 코드를 `RouteTrack` 전용에서 `Track` 공통으로**: `AppRunBridge`·`MapLaunchApplier`가 `LapLength`·`GetPoint`만 쓰는 곳은 `Track`으로, 경로 고르기(`HasRoute`·`SetRoute`)는 `RouteTrack`일 때만. 미니맵 코스 모양·입장 위치·같이 달리기 순간이동이 그대로 돌게
4. **아바타 구동 합치기**: `AvatarGaitDriver`를 `Experiments`에서 `Scripts/`로(정식). 섬 Y Bot은 `RunnerAnimator` 그대로, 새 아바타는 `AvatarGaitDriver` — 둘이 같은 러너 속도를 읽으므로 앱 코드는 어느 쪽인지 몰라도 됨. 걷기·달리기 판정을 센서 걸음 상태로 할지는 이 계획 밖
5. **품질**: `ScrunQuality`를 맵 공통으로(식생·섬 봇 부분은 있을 때만), 우주 루프에도 불러올 때 붙임 → 아이폰 30fps·렌더 배율·그림자·화면 꺼짐 방지·I-12 "품질 낮추기"가 그대로. Low에서는 호수 반사 카메라(`SpaceLoopLakeReflection`) 끔
6. **서버**: 코스 `crs_space_loop`(LOOP_3D, 3,000 m, 이름·설명은 Figma 홈 시안 문구 — 상준 확인) 마이그레이션. 섬 코스 3개는 ADR-0013 승인 전까지 그대로 두고, 승인되면 끔(맵 1개, 11/20 결정)
7. **에디터 확인(Windows)**: App 장면 → 로그인 → 코스 우주 루프 → 3·2·1 → 가짜 센서로 달리기 → 구간 1–5 지나감·미니맵·고스트·다른 러너(두 번째 계정) 보임·결과 화면. EditMode 테스트 통과
8. **아이폰 실측**(위 "맥 할 일")

## 판정
- 연결: 위 7번 흐름이 에디터에서 오류 없이 끝까지, EditMode 테스트 모두 통과
- 성능: 아이폰 Medium에서 모든 구간 30fps 유지(1% 낮은 프레임 25 이상), 그리기 호출 300 이하(기존 기준), 20분 뒤 발열로 품질이 떨어지지 않음 → ADR-0013 승인 제안
