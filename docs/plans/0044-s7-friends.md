## 지금 (코드에서 확인)
- 서버: `/v1/friends` 7개(추가·목록·달리는 친구·프로필·삭제·같이 달리기·피드)가 **모두 예시 응답**(`routers/friends.py`). DB엔 `friendships`(user_a < user_b 한 줄) 표와 `users.friend_code`(가입 때 `SCR-` + 4글자, 헷갈리는 0·O·1·I 뺀 32자)가 이미 있음
- 오류 코드 `SELF_FRIEND_CODE`·`FRIEND_CODE_NOT_FOUND`·`ALREADY_FRIEND`·`FRIEND_LIMIT_EXCEEDED`·`RATE_LIMITED`는 정해져 있음(`docs/api/README.md`)
- 실시간 허브가 누가 어느 코스 방에서 달리는지·이번 달리기 거리(`run`, 0041)를 앎 → "지금 달리는 친구"를 여기서 바로 뽑을 수 있음
- 앱: 아래 탭 "친구"는 빈 자리(`AppRoot` `PlaceholderScreen`). 러너 카드(D-12)엔 친구 배지 칸만 비워 둠(0041)

## 하는 것
1. **서버(DB 연결 + pytest)**
   - `POST /friends`: 코드는 대소문자·공백·하이픈 무시. 본인·없음·이미 친구·한쪽이라도 50명이면 각 오류. 성공하면 **서로 바로 친구**(G-07). 실패가 10분에 10번 넘으면 `RATE_LIMITED`(가설 값, 설정으로 뺌)
   - `GET /friends`: 닉네임·인증 마크 수(VERIFIED 러닝 수)·달리는 중이면 거리·마지막 러닝 시각(G-10 "20분 전 러닝"). 레벨은 BL-32(S8 지환) 전까지 `null`
   - `GET /friends/running`: 허브에서 친구 중 지금 달리는 사람(코스 이름·이번 거리·지금 페이스)
   - `GET /friends/{id}`·`DELETE /friends/{id}`: 친구가 아니면 `USER_NOT_FOUND`(남의 존재 여부를 안 알림). 프로필은 최근 러닝 10개
   - `GET /feed`: 친구들의 끝난 러닝(인증·미인증·대기) 최신순, 커서 20개씩. 대기(PENDING)는 마크 없음, 미인증은 "미인증" 마크(백로그 ②)
   - 스키마가 바뀌는 곳(`level` 선택, `lastRunAt`·`runningDistanceM` 추가)은 `docs/api/README.md`·노션 API 명세에 반영
2. **친구 추가(G-04–G-08)**: 내 코드 + 복사(`GUIUtility.systemCopyBuffer`, 아이폰에서 되는지는 확인 필요) + 공유(iOS `UIActivityViewController` Swift 함수 1개, ADR-0009 브리지, 에디터는 복사만), 코드 입력 → 완료 화면 / 오류 문구 4종(G-08 케이스별)
3. **친구 탭(G-01·G-02·G-04)**: 지금 달리는 친구(위) + 피드(아래), 탭에 들어올 때와 당겨서 새로고침 때 다시 받음. 0명이면 G-04, 달리는 친구가 없으면 G-02. 피드 시간은 "20분 전" 식(`RelativeTime`, 테스트)
4. **프로필·관리(G-09–G-11)**: 프로필(인증 마크 수·최근 러닝·더보기 → 삭제), 관리 목록("7/50명", 왼쪽으로 밀어 삭제 + 행 끝 삭제 버튼) → G-11 확인 시트 → 지움
5. **러너 카드(D-12)**: 친구면 "친구" 배지(앱이 친구 id 목록을 맵 입장 때 받아 둠)
6. **같이 달리기 버튼(G-01·G-03·G-09)**: 정할 것 4
7. 문서: `docs/api/README.md`, `docs/unity/unity_map.md`, 이 계획 진행, 노션 작업 표·API 명세

## 정할 것
1. **친구 코드 형식**: (가) **Figma대로 8글자**(지금 32자, `K7Q2M9XA`처럼), 개발 DB의 기존 코드는 마이그레이션에서 새로 만듦 **(추천: 지금 4글자는 경우의 수가 약 105만 개라 코드 = 피드를 보는 열쇠인데 맞혀 보기 쉬움. 8글자는 약 1조 개. Figma 문구 "8자리"와도 맞음)** vs (나) 지금 `SCR-XXXX` 유지하고 Figma 문구를 "4자리"로
2. **친구 맺기**: (가) **코드를 넣으면 요청·수락 없이 서로 바로 친구**(G-07) **(추천: 코드는 본인이 골라서 준 사람만 앎, 원치 않으면 삭제. 요청함·알림 화면이 Figma에 없음)** vs (나) 요청 → 상대가 수락
3. **맵에서 만난 사람 "친구 추가"(D-12 카드 💡)**: (가) **이번엔 안 함, 카드엔 친구 배지만** **(추천: 코드 없이 추가하면 모르는 사람이 내 피드를 보게 됨 → 하려면 정할 것 2의 (나) 요청·수락이 필요해 범위가 큼)** vs (나) 카드에서 요청 보내기
4. **같이 달리기 버튼**(BL-29는 S8): (가) **S7엔 버튼·G-03 시트까지 만들고, 확인하면 그 코스로 일반 입장. 시트의 "친구 근처에서 시작해요" 줄은 S8에 켬** **(추천: 친구 탭 모양이 S8까지 비지 않고, S8엔 입장 위치만 바꾸면 됨)** vs (나) S8까지 버튼을 숨김
5. **친구 근접 알림(D-26)**: (가) **계속 빼고 S8 같이 달리기 때 상준과 다시** **(추천: 친구끼리 같은 방에 있는 일은 같이 달리기로 들어올 때가 대부분이고, 0041의 이유(간격 카드가 늘 보임·알림이 묻힘)가 그대로)** vs (나) S7에 친구만 30초 간격으로 넣음
