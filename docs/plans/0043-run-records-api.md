## 하는 것
1. `GET /runs`: 내 끝난 기록(PENDING·VERIFIED·UNVERIFIED, 달리는 중·버린 것은 뺌) 최신순, 커서 20개씩. `month=YYYY-MM`은 **내 시간대**(`users.timezone`) 기준 달. 읽기 전에 `close_expired(user_id)`
2. `GET /runs/{id}`: 요약 + 출처(계기판·센서)·센서 값·계기판 값(인증 완료일 때)·그래프용 시계열(합친 1초 시계열을 최대 120칸 평균으로 줄임)·함께 달린 사람·고스트 id. 남의 기록이면 FORBIDDEN, 없으면 RUN_NOT_FOUND, 달리는 중·버린 기록도 RUN_NOT_FOUND
3. `PATCH /runs/{id}`: `shared`만 바꿈(끝난 기록만)
4. 함께 달린 사람: 정할 것 1
5. 고스트: 정할 것 2
6. pytest(목록 커서·달 경계·시간대·마감 지난 대기·남의 기록·공유·시계열 겹침·120칸), `docs/api/README.md`, 노션 API 명세 4줄, 노션 작업 표 [BE] 줄 담당 → 민재
