# 계획 0007: 소리를 더하면 속도 오차가 줄어드나 (SoundTrackDB, PC만)

- 상태: **완료** (2026-10-28). 결과: 소리를 더해도 안 나아짐([soundtrackdb.md](../speed/soundtrackdb.md) 8번). 앱은 안 바꿈. 마이크 제외 결정(10/28)을 다시 볼 근거가 되는지만 확인
- 데이터: SoundTrackDB `audio_m4a` 363개(약 1.9GB), 계기판 위 폰 마이크. 가속도와 같은 시간축
- 근거: 같은 연구실 CaNRun(2023)은 헬스장 소음 속에서 중간 대역 필터 + LSTM으로 걸음 수를 잼. 속도는 아무도 안 함

## 무엇을
1. ffmpeg로 16kHz 한 채널로 풀고, 10 ms 칸마다 대역별 세기(낮음 50에서 300, 중간 300에서 2000, 높음 2000에서 6000 Hz)
2. 20초 창마다 대역별 발소리 크기(봉우리 중앙값)와 바탕 소리 대비 비율 → 세션 한 점(계획 0006과 같은 방식)
3. 비교: 충격만 / 소리만 / 충격 + 소리, 보정 1·2·3개, 범위 안·밖. 같은 속도 두 번의 차이(잡음 바닥)
4. 판정: 3개 보정·범위 안 오차가 0.44에서 눈에 띄게 줄면 마이크 재논의 근거, 아니면 접음
5. 결과 `docs/speed/soundtrackdb.md`, 스크립트 `speedlab/exp/soundtrackdb_audio.py`

## 주의
- 그 헬스장 소음이 우리 헬스장과 같다는 보장 없음. 좋게 나와도 우리 헬스장에서 다시 확인
- 폰마다 마이크 감도·자동 음량 조절이 달라 소리 크기 자체는 흔들릴 수 있음 → 바탕 소리 대비 비율도 같이 봄
