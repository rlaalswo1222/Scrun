## 하는 것
1. **Figma I-07–I-09 읽기**: 화면 번호·문구·모양을 이 문서에 적고, 코드 주석의 번호를 Figma에 맞춤(`Feedback.cs`·`FeedbackTests`·`unity_map.md`)
2. **공통 컴포넌트 `StateView`**(인수 조건 ③): UXML 틀 하나(`UI/StateView.uxml`) + C# 한 곳(`UI/StateView.cs`) + 스타일 한 파일(`UI/States.uss`, 상준이 여기만 고치면 전 화면에 반영)
   - 스켈레톤: 화면이 줄 모양을 고름(목록 줄·카드·상세 세 가지), 회색 막대가 천천히 깜빡임(움직임 줄이기 설정이면 안 깜빡임)
   - 실패: 그림 자리 + 제목 + 설명 + "다시 시도". 네트워크 없음(기기 망이 없음)과 그 밖의 오류(서버·시간 초과)를 문구로 나눔
   - 빈 상태: 문구 + (있으면) 버튼. 지금 화면마다 있는 빈 목록 문구를 이걸로
3. **첫 불러오기를 `Feedback.Load` 한 곳에서**(정할 것 1·2): 아직 보여 줄 게 없을 때 덮개 대신 그 화면의 스켈레톤 → 성공하면 내용, 실패하면 그 자리에 실패 상태(안내창은 안 띄움). 다시 보일 때 조용히 받는 지금 규칙은 그대로
4. **연결이 돌아오면 저절로 다시**(정할 것 3): 네트워크 없음 상태가 떠 있는 동안 2초마다 기기 망을 보고, 생기면 한 번 다시 불러옴. 화면이 숨으면 멈춤
5. **10개 화면 옮기기**: 각 화면의 `load-failed`·빈 목록 칸을 `StateView`로 바꾸고 화면별 문구만 남김. 홈은 지환이 다시 만드는 중(BL-31)이라 빼고 지환에게 쓰는 법을 알림. 맵 입장(I-10 로딩·I-11 카드)은 맵 전용이라 그대로
6. **확인**: EditMode(스켈레톤 → 내용, 실패 → 다시 시도 → 내용, 네트워크 없음 → 망이 생기면 저절로, 다시 보일 때 조용히, 빈 상태), 에디터 Play에서 서버를 끄고 켜며 10개 화면 캡처, 아이폰에서 비행기 모드 켜고 끄기(노션 공통 아이폰 확인 줄 추가)

## 정할 것
1. **첫 로딩 표시**: (가) **화면 안 스켈레톤, 화면 전체 덮개 "잠시만요"는 버튼 동작(저장·보내기)에만 (추천: 백로그 ① 그대로. 덮개는 탭·뒤로 가기까지 막아서 느린 망에서 앱이 멈춘 것처럼 보임)** vs (나) 지금 덮개 유지
2. **첫 불러오기 실패**: (가) **화면 안 실패 상태만, 안내창은 안 띄움 (추천: 지금은 안내창과 화면 안 칸이 같은 말을 두 번 함. 백로그 ② "화면에서 재시도")** vs (나) 지금처럼 둘 다
3. **연결이 돌아오면 저절로 다시 불러오기**: (가) **함 (추천: 지하철·엘리베이터에서 흔한 경우. 사용자가 버튼을 찾지 않아도 됨, 2초 간격 확인은 가벼움)** vs (나) "다시 시도" 버튼만
4. **모양**: (가) **지금 UI Kit 색·글꼴로 `States.uss`에 임시 모양을 만들고 상준이 다듬음 (추천: 상준 디자인 줄이 시작 전이고 S8이 11/23까지. 파일 하나라 다듬기 쉬움)** vs (나) 상준 모양이 나올 때까지 기다림
