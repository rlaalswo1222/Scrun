## 하는 것
1. **진짜 속도 → 내 아바타**: 앱에서 들어오면 `MapLaunchApplier`가 플레이어의 속도 소스를 `NativeSpeedSource`로 바꾼다(키보드 소스는 끔). 앱 쪽 `RunLink`(정적, `MapLaunch`와 같은 방식)에 "달리는 중" 스위치를 두고, 스위치가 꺼져 있으면 속도 0(카운트다운 전에 아바타가 먼저 가지 않게). 섬은 매 프레임 내 누적 거리를 `RunLink`에 적는다. 섬만 Play할 땐 지금처럼 키보드
2. **달리기 시작·시계**: `RunSession`(앱)이 시작 시각·거리·목표 진행을 들고, 지환 카운트다운이 끝나면 `RunSession.Start()`를 부른다. 지환 D-07·카운트다운이 들어오기 전엔 D-06 "시작할게요"에서 바로 Start(임시, 그 줄에 주석). 일시정지·종료·`POST /runs`는 S5
3. **실시간 방 서버** (FastAPI, `backend/app/realtime/`)
   - 접속: 입장 응답 `realtime = {url, token}`. 토큰은 JWT `typ=rt`, `sub`=사용자, `map`=맵 ID, 6시간. 주소 `wss://<서버>/v1/realtime`, 토큰은 `Authorization` 헤더(리뷰: 주소에 넣으면 접속 기록에 남음). 같은 사람이 두 번 붙으면 앞 연결을 닫음(닫는 코드 4001)
   - 메시지(JSON, 모양은 `docs/api/realtime.md`에 정리): 폰 → 서버 `state {d, v, running}` 초당 2번, `ping {t}`. 서버 → 폰 `welcome`(서버 시각, 코스 길이, 지금 러너들), `states`(모든 러너의 d·v, 초당 2번 한 번에), `joined`·`left`, `pong`(서버 시각 포함: 왕복 지연 실측, 나중에 봇 위치 계산에도 씀). 리뷰 뒤 추가: 폰 → 서버 `leave`(맵 나가면 바로 빠짐), 첫 `state` 전엔 다른 사람에게 안 보임
   - 끊김: 서버는 30초 동안 "끊긴 러너"로 두고(그 사이 다시 붙으면 `joined`·`left` 없이 이어짐) 지나면 `left`. 앱은 1·2·4·8초 간격으로 다시 붙고, 붙으면 `welcome`으로 방 상태를 통째로 다시 받음(ADR-0010 "다시 붙으면 방 상태 다시 받기")
   - `runnersNow`·입장 인원 = 실시간 연결 수 + "입장했지만 아직 안 붙은 사람(입장 2분 안)". `occupancy.count_present` 한 곳만 바꿈
   - 입장 위치(BL-25 ②): 방에 달리는 사람이 있으면 그중 한 명의 20–40m 뒤(앞사람이 보이게), 없으면 지금처럼 랜덤
4. **다른 러너 그리기** (BL-21 ③④⑥): 섬 쪽 `AppRunBridge`가 `RunLink`의 러너 목록을 보고 씬의 봇 몸 하나를 복제해 다른 사람을 만든다. 받은 d·v로 **앞으로 내다보고(속도 × 경과 시간) 새 값이 오면 0.5초에 걸쳐 부드럽게 맞춤**(1차원·거의 일정한 속도라 지연 버퍼보다 낫다고 봄, 가설 → "확인"에서). 앱에서 들어오면 섬의 가짜 봇 5명·무리 12명은 끔. 머리 위 이름표는 닉네임(레벨 배지는 레벨이 생기는 S8에). 들어옴·나감은 가벼운 토스트(⑤)
5. **기본 HUD** (BL-12 ②④⑤): 가로, 거리·시간·목표 대비 진행 막대, 왼쪽 아래 간격 카드(앞뒤 가장 가까운 러너 이름 + "12m 앞"/"8m 뒤", 고리 코스라 앞뒤는 반 바퀴 기준). **속도·페이스는 안 보임**(②). 개발 빌드에서만 속도·왕복 지연 작은 글씨(시연·실측용). 미니맵(③)·구간 알림(⑦)·속도 기록(⑥)은 S5
6. **연결 인터페이스**: 화면 코드는 `IRunTogether`(연결·내 상태 보내기·러너 목록·이벤트)만 본다. 구현은 `WsRunTogether`(진짜). 메시지 처리는 전송과 떼어 `RunTogetherRoom`으로(테스트는 이걸로, 따로 가짜 구현은 안 만듦). 나중에 Photon 등으로 바꿀 때 이 하나만 바꿈(ADR-0010 "다시 검토할 조건")
7. **테스트**: 서버 pytest(토큰 거절, 입장 → 붙기 → `welcome`, 두 명 `states`·`joined`·`left`, 끊겼다 30초 안 재접속, 인원 세기). Unity EditMode(간격 계산·반 바퀴, 내다보기·맞춤, 메시지 읽기, 재접속 간격)

## 정한 것 (11/11 민재, 추천대로)
1. **Unity WebSocket**: .NET 내장 `ClientWebSocket`(추천: 패키지 추가 없음, async라 지금 API 코드와 같은 모양) vs NativeWebSocket(ADR-0010 참고 링크, 패키지 하나 추가). 내장이 아이폰(IL2CPP)에서 붙는지는 첫날 맨 먼저 확인(가설), 안 되면 NativeWebSocket
2. **섬의 가짜 봇 5명·무리 12명**: 앱에서 들어오면 끔(추천: 기기마다 위치가 달라 "같은 맵" 약속이 깨지고, 이름표 없이 사람처럼 보임) vs 둠
