# 계획 0065: 애플워치 앱 — 팔 스윙 확인 단서 + 손목 표시

## 맥 할 일 (1번 시험, 반나절)
저장소 밖 실험이 아니라 `ios/WatchSpike/`에 작은 Xcode 프로젝트(아이폰 앱 + 워치 앱)를 만들어 아래를 확인하고 결과를 "진행"에 적는다. 서명은 팀 공용 무료 팀(TEAM07 Capstone), 번들 `com.scrun.watchspike`·`com.scrun.watchspike.watchkitapp`(본 앱 ID는 건드리지 않음). 워치 = 상준 애플워치(민재 아이폰에 페어링됨), 워치 설정에서 개발자 모드 켜기
1. **설치**: 무료 팀으로 워치 앱이 깔리고 실행되는지(몇 번 막히면 오류 문구 그대로 적기)
2. **화면 꺼진 채 센서**: 손목을 내려 화면이 꺼진 상태로 2분 동안 `CMMotionManager` device motion 100 Hz가 계속 들어오는지, 실제 빈도·끊김. 세 가지로 비교
   - (a) 아무 세션 없이 → 멈추는지(멈추면 아래가 필요하다는 근거)
   - (b) `WKExtendedRuntimeSession`(physical therapy 종류, 건강 권한 없음, 최대 1시간)
   - (c) `HKWorkoutSession`(HealthKit, **심박 읽기는 요청하지 않고** 운동 쓰기만) → 무료 팀에서 HealthKit 기능이 켜지는지, 권한 화면에 뭐가 뜨는지 캡처
3. **아이폰으로 보내기**: `WatchConnectivity` `sendMessage`로 1초마다 작은 값(시각·팔 회전 폭·팔 주기)을 아이폰 앱으로. 아이폰 앱이 앞에 떠 있을 때(실제로는 Unity 앱이 계기판 위에서 켜져 있음) 지연·빠짐을 2분 동안
4. **배터리**: (b) 또는 (c)로 20분 돌렸을 때 워치 배터리 몇 % 줄었는지
5. 반대로 아이폰 → 워치로 1초마다 "시간·약 N km/h"를 보내 워치 화면에 띄우기(손목 표시가 되는지)

- 상태: **승인**(2026-11-21 민재 "워치도 지금 개발하자") · 1번 시험 대기(맥)
- 담당: 민재
- 왜: 11/21 헬스장(계획 0064, 1명·1회 → 가설)에서 9 km/h 세게 밟기 때 폰 충격 +51%인데 워치 팔 회전 +9% → 튀는 값을 가리는 독립 단서. 몸에 붙어 폰 위치·계기판 울림과 무관(다른 날 치우침에 강할 수도, 가설), 에어팟이 끊길 때 걸음 수 백업(팔 주기 = 두 걸음), 달리는 중 손목에서 시간·약 속도를 봄(폰은 계기판 위라 잘 안 보임). 한계: 걸음 수 고정에서 10과 11 km/h는 못 가름(짧은 구간 1번)
- 우선순위: 주간 목표 리마인더(BL-46)를 뒤로 미룸(11/21 민재). 맵·아바타 연결, HUD 시간·약 속도, 친구 인증 기록은 그대로 먼저

## 하는 것
1. **맥 시험**(위). 무료 팀에서 설치·화면 꺼진 센서가 안 되면 워치는 종강 뒤 Apple Developer 가입 뒤로 미룸(그때까지 PC 분석만)
2. **ADR-0014**(ADR-0007 보충): 워치는 선택 기기(있으면 확인 단서 + 손목 표시, 없어도 지금과 같음), 백그라운드 방식(b·c 중), 건강 권한 범위(심박은 안 읽음, 11/21 민재 결정), 개인정보처리방침에 들어갈 문장
3. **PC 분석**(`speedlab/exp/`): 0064 기록(11/21 워치, 11/22 에어팟 + 워치)으로 0064 걸음 수 규칙에 워치 팔 회전을 더했을 때 — "폰 충격이 오르는데 팔 회전이 그대로면 안 올림" — 세게 밟기가 더 막히는지, 10/29처럼 진짜 속도 변화는 안 막는지
4. **구현**(1·2·3 뒤)
   - 워치 앱(Swift, SwiftUI): 시작·정지는 아이폰 달리기 시작·끝을 따라감(워치에서 따로 누르지 않게), 화면은 시간 크게 + 약 N km/h
   - 워치 계산: 100 Hz → 1초마다 팔 회전 폭·팔 주기만 아이폰으로(원본은 안 보냄)
   - 아이폰 Swift 플러그인: 워치 값 받기 → `SpeedEstimator.swift`·`fusion_live.py`에 같은 규칙(정답 파일 `speedlab/golden/` 다시, 맥 재생 비교)
   - Unity 빌드 후처리 `IosPostprocess.cs`에서 워치 타깃을 Xcode 프로젝트에 자동으로 붙이기(번들 `com.scrun.app.watchkitapp`), 손으로 Xcode 만지지 않게
   - 앱 설정에 워치 연결 상태(연결됨·없음)만, 워치 없으면 지금과 똑같이 동작

## 판정
- 1번: 무료 팀 설치 + 화면 꺼진 채 100 Hz 2분 끊김 없음 + 아이폰으로 1초 값 빠짐 5% 이하 → 2번으로
- 3번: 세게 밟기 튐이 걸음 수 규칙만보다 더 줄고, 10/29 M·B 안정 오차·반응 시간이 나빠지지 않음 → 4번 계산에 넣음. 못 넘으면 워치는 손목 표시·걸음 수 백업만
