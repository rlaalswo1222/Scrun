# 계획 0010: 아이폰 안에서 실시간 속도 (계기판 아이폰 + 에어팟) — 아이폰 전용 앱 시험

- 상태: **구현** (2026-10-29 사용자 요청·승인, 헬스장 시험 전). Swift는 맥에서 첫 빌드 전
- 왜: 아이폰 전용으로 간다면 "계기판 아이폰 + 에어팟, 짧은 보정 뒤 원하는 속도로 달릴 때 실시간으로 맞는지"가 핵심. 노트북·와이파이 없이 폰 안에서 계산(10/29 헬스장 와이파이 70초 끊김)
- 근거: 10/29 B 러닝머신 기록을 실시간처럼 다시 돌린 결과(`speedlab/fusion_live.py`, 보정 7·8·9·10 중 달리기 8·9·10) 8에서 10 km/h 평균 0.34(폰만 0.46), 7 km/h 걷기 판단 81/82틱. 에어팟 비중을 같은 기록에서 배워 낙관적

## 무엇을
1. `ios/SpeedRecorder/SpeedEstimator.swift` = `speedlab/fusion_live.py`(기준 구현)를 옮김
   - 걷기·달리기: 에어팟 "0.5 g 아래 시간" 걸음당 70 ms 이상이면 달리기, 에어팟 끊기면(0.5초 넘게 안 옴, 창 안 70% 미만) 폰 걸음 수 150. 2.5초 이어져야 바꿈
   - 달리기: 에어팟 있으면 a + b·ln(충격) + 2.598·흔들림 폭(B에서 배운 고정값), 끊기면 a' + b'·ln(충격). a·b는 이번 보정에서 달리기로 판단된 구간으로
   - 걷기: −3.45 + 0.0732·걸음 수(두 사람, 다리 길이 비슷 → 확정 아님)
   - 충격·걸음 수: StepSpeed.cs 계산(포락선 100 Hz), 필터는 샘플마다 이어서. 최근 2초 중앙값을 보여 줌
2. 앱: "보정 1분 + 자유 달리기" — 7(25초), 8, 9, 10(각 15초, 앞 5초 버림, 올라가는 순서) → 자유 달리기 20분. 화면에 추정 속도(크게)·폰만 값·걷기/달리기·에어팟 끊김, 실제 속도 ±버튼(나중 오차 계산용)
3. 노트북 없이 기록(폰 문서 폴더 CSV: estimate, stage, mark 추가). 노트북이 연결되면 지금처럼 보냄. 백업 CSV 같은 줄 여러 번 들어가던 버그 수정
4. 끝난 뒤: 폰 폴더를 맥으로(devicectl 또는 파일 앱·AirDrop) → `data/runs/<id>/`에 두고 오차 계산
