# 계획 0071: 몰려도 멈추지 않게 — 동시 처리 제한·빠른 거절

- 상태: **승인**(2026-11-25 민재 "0071 해봐": 번호표 12장·2초·503·실시간 연결 제한은 뺌으로 시작, 측정으로 10·12·15 비교). 설명 그림: [0071-overload.html](0071-overload.html)
- 담당: 민재
- 왜: 계획 0070 기준선([docs/perf/README.md](../perf/README.md))에서
  - 동시 200명(S1)이면 DB 연결을 30초 기다리다 500(`QueuePool limit … timeout 30`), **시험이 끝난 뒤 8분 넘게 회복 못 함**(바로 뒤 50명 시험 두 번 실패)
  - 100명이 한꺼번에 로그인·입장(S3)하면 "연결을 쥔 요청은 다음 단계 스레드를 못 받고, 스레드 40개는 연결 15개를 기다리는" 멈춤. #138로 크게 줄었지만 한 번은 재현됨 → 구조 문제(스레드 40 > 연결 15)가 남음
  - 운영도 같은 구조(단일 uvicorn, 풀 기본값). 사용자가 적어 지금은 안 보이지만, 발표 시연·헬스장에서 여럿이 동시에 끝내면 몰림
- 결과물: 순간 폭주에도 **받은 요청은 제때, 못 받을 요청은 바로 503**, 폭주가 끝나면 **몇 초 안에 정상**

## 하는 것
1. **동시 처리 제한(비동기 세마포어)** `app/core/admission.py`: HTTP 요청은 번호표 N장 중 하나를 받아야 라우터로 감. 못 받으면 스레드·DB 연결을 쥐지 않고 비동기로 기다림 → 안에 있는 요청 수 ≤ N ≤ 연결 수라 멈춤이 구조적으로 안 생김
2. **빠른 거절(백프레셔)**: 번호표를 W초 안에 못 받으면 503 `SERVICE_UNAVAILABLE` + `Retry-After: 1`. 앱은 이미 서버 오류를 "다시 시도" 화면으로 보여 줌(문구 확인)
3. ~~끊긴 요청 버리기~~ → **빼기로(구현 때)**: 미들웨어에서 끊김을 보려면 요청 본문을 받는 통로(receive)를 건드려 POST 본문(사진)을 잃을 위험이 있음. 대신 대기 상한 W초가 같은 효과 — 번호표를 W초 넘게 못 받은 요청은 바로 503이라 쌓이는 양이 W초치로 묶임
4. **연결 풀 맞추기**: 풀은 그대로 15(5 + 넘침 10) = 번호표 12 + 실시간 몫 3. HTTP 요청은 모두 `get_db` 세션 하나 = 연결 하나(코드 확인), 실시간은 입장·퇴장 때 따로 짧게. 연결 기다림 상한 30초 → 5초(`DB_POOL_TIMEOUT_S`)
5. **요청 로그에 `queue_ms`(번호표 기다린 시간)**, 거절은 `status 503`(라우팅 전이라 `path "-"`), `server_log_stats.py`가 503과 그 밖의 5xx를 나눠 셈. 컨테이너 안 헬스체크(루프백 + `X-Scrun-Probe`)만 제한 밖, 밖에서 붙인 헤더는 무시하고 Caddy에서도 지움
6. 설정은 환경 변수(`ADMISSION_LIMIT`·`ADMISSION_WAIT_S`·`DB_POOL_TIMEOUT_S`, 번호표 ≤ 연결 합계 15가 아니면 ConfigError), 테스트: 제한 넘는 동시 요청 → 503, 기다리다 들어감, 헬스체크 루프백만, 본문을 다 보낸 뒤 반납, 실패해도 반납, 풀 시간 초과 → 503
7. **리뷰 반영(11/25)**: 처음엔 `BaseHTTPMiddleware`라 응답 머리가 나갈 때 번호표를 반납 → `get_db` 세션이 닫히기 전에 다음 요청이 들어와 연결이 N을 넘음 → **순수 ASGI 미들웨어**로 바꿔 응답·세션 정리가 끝난 뒤 반납. 풀 기다림 초과(SQLAlchemy `TimeoutError`)는 500 대신 503 `DB_BUSY`

## 정할 것
1. **N(동시 처리 수)·W(기다리는 상한)**: 추천 N = 12(풀 15 중 실시간 몫 3), W = 2초. 기준선 다시 잰 값(5분)으로 N 10·12·15를 비교해 고름
2. **거절 코드**: 503(서버가 바쁨, 추천) vs 429(이 사용자가 너무 많이 보냄 — 뜻이 다름)
3. 실시간 WebSocket 연결 수 제한도 같이 둘지(지금은 맵 정원 20 × 코스 5 = 100이 사실상 상한)
