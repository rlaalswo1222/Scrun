## 하는 것
1. **서버: 달리는 쪽 runs API를 DB로** (`routers/runs.py`, pytest)
   - `POST /runs`: `runs`에 ACTIVE로 한 줄. 같은 `clientRunId`면 처음 결과. 코스는 `mapInstanceId`(`map_<courseId>`)에서, 맵 입장 기록(`course_entries`)과 다르면 400. 내 이전 ACTIVE가 있으면 정할 것 4
   - `PUT /runs/{id}/samples`: `offsetS`마다 덮어씀(같은 묶음이 다시 와도 하나). ACTIVE만, 끝난 기록이면 `RUN_ALREADY_FINISHED`, 남의 기록이면 `FORBIDDEN`
   - `POST /runs/{id}/finish`: ACTIVE → PENDING(인증 대기), 센서 거리·시간·종료 시각 저장, 공식 값은 일단 센서 값(인증 뒤 지환이 바꿈). 인증 기한(`verification_deadline`)은 지환 인증 계획에서 정하고 지금은 비움
   - `GET /runs/active`·`POST discard`(BL-37 서버 쪽만, 복구 화면 I-04는 따로): 24시간 안의 ACTIVE 하나 / ACTIVE → DISCARDED
2. **앱: `RunSession`에 일시정지·종료·시계열** (EditMode 테스트)
   - 일시정지: 시간이 멈추고 거리도 안 늚(`RunLink.Moving = false` → 아바타 멈춤, 실시간 `running=false` → 남의 화면에도 멈춤). 계속하면 이어서
   - 속도 시계열(BL-12 ⑥): 1초 간격, 아바타 속도(`NativeSpeedSource` 값 = 서버·남의 화면과 같은 값). 일시정지 구간은 정할 것 2
   - 60초마다 `PUT samples`로 묶음 올리기, 종료 때 남은 묶음 → `POST finish`. 실패하면 다시 보내기(#49 `RunStartSender`와 같은 방식, 리뷰 8번대로 간격표 하나로). 다 실패해도 기기에 남겨 다음 실행 때 보냄(BL-37과 이어짐)

   - D-10 HUD 오른쪽 위: X(나가기) → 일시정지 버튼
   - D-17 일시정지: "계속" / "종료"
   - D-18 종료 확인: "정말 끝낼까요?" → 예면 `POST finish`
   - D-19 목표 달성: 처음 도달한 순간 한 번, "계속 달리기" / "마무리하기"(→ D-18 없이 바로 끝내기). 햅틱은 쓰지 않음(BL-12 ⑧)
   - D-22 종료 → 계기판 인증 안내: "계기판 촬영하기"(지환 E-02) / "촬영 없이 마무리 (미인증)". 인증 화면이 아직 없으면 정할 것 3
   - (11/16 Figma를 읽고 고침: 처음 초안은 D-19·D-22를 거꾸로 적었음)
   - Figma D-10·D-17·D-18·D-19·D-22 프레임은 구현 첫 단계에서 읽고, 다른 점은 아래 "진행"에 적음. 문구는 상준 확인
