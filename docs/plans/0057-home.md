## 하는 것
1. **서버 `GET /home`을 DB로**(마이그레이션 없음, 응답에 `nickname` 한 칸만 더함 — 머리줄 "닉네임 님"을 요청 하나로): 주간 목표 = `weekly_payload`, 레벨 = `progress_payload`, 달리는 친구 = `/friends/running`과 같은 함수, 코스 = `/courses`와 같은 목록(지금 달리는 사람 많은 순), 최근 기록 = 끝낸 러닝 최근 3개(마감 지난 것은 먼저 닫음). 라우터 안 계산은 함수로 빼서 두 곳이 같이 씀. pytest: 새 사용자(빈 값)·목표 있음·달리는 친구·다른 사람 기록이 안 섞임. openapi·예시 다시 뽑기
2. **앱 `Home.uxml`·`Home.uss`(UI Kit 변수)·`HomeScreen`**: 위 표대로 상태를 `HomeText.Pick(home)`(화면 없이 테스트)로 고름. 들어올 때마다 `Feedback.Load`(처음만 스켈레톤 I-08, 다시 보일 땐 조용히), 실패는 `StateView`(I-07·I-09) — 그래도 큰 버튼은 동작
3. **이동**: 큰 버튼·"전체 보기" → C-01, 코스 카드 → C-02, [목표 정하기] → H-08 시트(지환 `WeeklyGoalStatusScreen`의 시트를 빼서 같이 씀, 0054 "안 고친 것"), 위 카드(목표 있음) → H-07, 레벨 줄 → H-04, 친구 줄 → 친구 탭, "같이 달리기" → 지금 같이 달리기 흐름(#79). 탭은 `Navigator.ShowTabRoot`
4. **I-04를 Figma대로**: 시트 → 가운데 안내창(공통 `.dialog` 스타일 + 어두운 덮개). 문구 Figma 그대로("1.8km · 10:12"는 폰 기록 값). [복구하고 인증하기] = 지금 "마무리하기", [기록 버리기] = 지금 "버리기"(정할 것 3). 복구 로직(`RunRecovery`)은 안 건드림
5. **E-01을 Figma대로**: 제목줄·"수고했어요!"·안내·"오늘의 러닝" 카드(거리·시간·평균 페이스·목표)·경고 문구·[계기판 인증하기]·[미인증으로 저장]. 인증 마감이 지나 촬영이 안 되는 러닝은 지금처럼 촬영 버튼 없이 "결과 보기"
