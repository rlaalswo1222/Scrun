## 하는 것
1. **토큰·컴포넌트 한 벌**(`Resources/UI/Space.uss` 새로): 미리보기 `tokens.css` 값을 USS 변수로 그대로(이름도 같게, 예 `--bg-surface`), `ui.css`의 컴포넌트를 USS 클래스로: 화면·내비 바·글자 단계·버튼(주·보조·위험·카카오, 기본·누름·비활성·로딩)·칩·알약·토글·유리 카드·목록 줄·아이콘 원·입력칸·체크 줄·시트·대화상자·통계 칸·진행 막대. 0061 `OnboardingSpace.uss`·0062 `HomeSpace.uss`는 이 한 벌로 합침(같은 모양 두 벌을 안 둠)
2. **UI Toolkit이 못 그리는 것**: 유리(배경 흐림)·그라데이션·글로우 → 반투명 채움 + 위 가장자리 1px 밝은 선으로 대신하고, 바탕·글로우는 그림(미리보기 `img/bg_*`과 같은 원본)으로. 아이폰에서 미리보기와 나란히 놓고 차이를 적어 상준 확인
3. **움직임**(미리보기 `ui.css`·`fx.css`, 토큰 duration·ease): 화면 넘김(밀기·뒤로·페이드, 탭 전환은 그 방향에서), 버튼 누름, 시트·대화상자 올라옴, 결과 아이콘 튐·흔들림, 숫자 올라가기, 그래프 왼쪽부터 그리기, 콕핏 탭 바(키 눌림·LED). USS transition + 화면 코드 몇 줄(`ScreenNav`에 넘김 효과 한 곳). "동작 줄이기"면 페이드만
4. **화면**(UXML·USS만, 서버 호출·흐름·테스트는 그대로). 미리보기 화면 → 앱 화면
   - A: 로그인·약관·프로필·권한·이어폰·주간 목표·완료·보정 안내·보정(가로) — 이미 우주인 8개는 새 토큰으로 맞춤
   - B·C: 홈·코스 목록·코스 상세·맵 로딩(I-10)
   - E: 종료 요약·촬영 안내·사진 확인·읽는 중·읽은 값 확인·인증 완료·불일치·재촬영·읽을 수 없음·마감·레벨업·결과·대조 시트
   - F: 기록·기록 상세 / G: 친구·추가·추가됨·프로필·관리 / H: 마이·레벨·주간 목표·재보정·설정·프로필 편집 / I: 권한 거부·인터넷 끊김·맵 가득 참·잠시 오류·불러오기 상태
