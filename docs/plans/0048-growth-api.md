## 하는 것
1. `core/growth.py`: 레벨 = 누적 거리가 넘은 임계값 수 + 1(임계값은 서버 설정 `GROWTH_LEVEL_M`, 기본 3000·10000·25000·50000·100000), 러닝복 단계 = min(레벨, 6), 다음 레벨까지 남은 거리
2. **기록이 정해질 때 한 번만 반영**: 인증 완료·미인증으로 정해지는 모든 곳(사진·확인·건너뛰기·마감으로 닫힘)에서 같은 트랜잭션에 `run_rewards` 한 줄(전후 값, 주간 목표 인정 여부). 인증 완료면 `user_progress`를 잠그고 경험치(공식 거리)·횟수를 더함. 같은 기록은 두 번 안 더함(`run_rewards` 기본 키)
3. API를 DB로: `GET /runs/{runId}/rewards`(내 기록·정해진 것만, 아니면 `RUN_NOT_FINISHED`), `GET /users/me/progress`, 인증 응답의 `rewards` 채움
4. 주간 목표 칸(`weeklyGoal`): `core/weekly.py` — 목표가 있으면 설정일부터 7일 주기(사용자 시간대)로 이번 주기 인정 횟수·목표, 없으면 목표 null. 지환 BL-30(주간 목표 API·화면)이 이 함수를 그대로 씀(정할 것 2)
5. 기존 기록: 마이그레이션에서 정해진 기록을 시간순으로 다시 계산해 `run_rewards`·`user_progress`를 채움(정할 것 3)
6. 테스트: 레벨 경계(2999·3000·100000 m), 인증 완료만 더함, 미인증·마감은 0, 같은 기록 두 번 안 더함(동시 확인 포함), 주간 주기 경계(설정일 + 7일, 시간대), 마이그레이션 다시 계산. 문서 `docs/api/README.md` "판정은 서버"·`data_model.md`, 노션 API 명세 3줄
