docs/
  adr/                   ← 새로: 기술 의사결정 기록
  plans/                 ← 새로: 기능별 1쪽 계획 (이 문서가 첫 번째)
  product/               ← 유저플로우 v1·v2·초안, 유스케이스      (docs/ 바로 아래에서 이동)
  speed/                 ← 속도 추정: 현재 결론 README + 10/28 실험 + 아이디어 (docs/log/에서 이동)
