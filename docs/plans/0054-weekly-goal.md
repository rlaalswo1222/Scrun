## 하는 것
1. **서버 `GET /users/me/weekly-goal`**: 목표가 없으면 빈 응답(`targetCount=null`). 있으면 오늘(사용자 시간대)이 든 주기의 목표·시작·끝(마지막 날 포함)·인정 횟수(`counted_in`)·남은 날(오늘 포함), 변경 예약(이번 주기 목표와 지금 목표가 다르면 지금 목표), 이력 = 이번 주기 앞의 주기 최대 7개(설정일 전은 없음, 옛 것부터)
2. **서버 `PUT`**(1–7): 처음이면 오늘을 설정일로 바로 적용. 이미 있으면 **다음 주기부터**: 설정일부터 이번 주기까지 주기 줄이 없는 주기에 지금 목표를 적어 굳히고(`weekly_goal_cycles`, 지난 이력·결과 화면 횟수가 바뀌지 않게) 목표를 새 값으로. 같은 주에 여러 번 바꾸면 마지막 값, 이번 주 목표로 되돌리면 예약 없음. 응답은 GET과 같은 모양
3. pytest: 처음 설정·바로 적용, 7일 경계(6일째·7일째), 사용자 시간대(서울 자정 직후), 인증 완료 + 5분만(미인증·4분 59초·다른 주기 제외), 변경은 다음 주기부터·이력 목표 그대로, 같은 주 여러 번·되돌리기, 1–7 밖 400, 이력 7개·설정일 전 없음, 결과 화면(E-11) 주간 칸과 같은 횟수. `stub_requests` → `REAL`·`real_examples`, `docs/api/README.md`·openapi·노션 API 명세 2줄
4. **앱 H-07 `WeeklyGoalStatusScreen`**(마이 탭 "주간 목표"에서, "준비 중" 대신): 이번 주 카드(N / M회, 목표 수만큼 동그라미, 채운 만큼 라임 체크), 최근 8주 막대(높이 = 횟수/목표, 달성 파랑·미달성 연한 파랑·이번 주 라임), "목표 변경" → H-08. 목표가 없으면 정할 것 1
5. **앱 H-08 변경 시트**: −/+·1–7 칩·안내 문구·저장(PUT)·취소. 저장하면 H-07을 새로 그림. 예약이 있으면 카드 아래 "다음 주부터 N회"(정할 것 2)
6. 순수 계산 `Run/WeeklyGoalText.cs`(EditMode): 카드 글자·동그라미 수, 막대 높이·색 종류, 예약 문구, 없음·처음 설정 문구. DTO `WeeklyGoal`에 `CycleStart·CycleEnd·History` 추가
7. 확인: pytest, EditMode, 에디터 Play(로컬 서버: 목표 없음 → 정하기 → 가짜 OCR로 5분 이상 인증 → 1 오름 → 변경 → 예약 줄), 문서 `unity_map.md`·`data_model.md`·계획·handoff·노션 작업 표 두 줄
