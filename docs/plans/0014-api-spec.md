## 노션 API 표의 칸
도메인 · 주소 · 동작(GET 등) · 기능 · 상태(시작 전 → 명세 검토 → 스텁 → 구현 → 테스트 완료) · 로그인 필요 · 화면 ID · 백로그 번호 · 유스케이스 · BE 담당 · 앱(Unity 연결) 담당 · 메모 · `/docs` 링크

도메인: Auth · User(내 정보·탈퇴·닉네임 확인·보정값·주간 목표) · Course · Run(시작·끝·속도 시계열·세션 복구·기록 목록·상세·고스트 시계열) · Verification(OCR 위치 미정이라 자리만) · Progress(레벨·경험치·인증 마크·임팩트) · Friend(코드·추가·삭제·피드·달리는 친구) · Event(PRD 2.4 지표) · 실시간 공동 맵(REST 아님, 메시지 이름·필드만, 전송 방식은 BL-36 뒤)

## 공통 규칙 (`docs/api/README.md`)
- 주소 `/v1/...`. 로그인은 카카오 iOS SDK 토큰 → `POST /v1/auth/kakao` → 우리 access(짧게)·refresh 토큰. 이후 요청은 `Authorization: Bearer {accessToken}`. 제공자별 계정 연결을 따로 저장해 Apple 로그인을 나중에 붙여도 구조가 안 바뀜(Q-39). 처음이면 `isNewUser` → `POST /v1/auth/signup`(약관·닉네임·키·몸무게)
- 응답 껍데기(DU 방식): `resultType`(SUCCESS/FAIL) · `success.data` · `error{code, message, details}` · `meta{timestamp, path, requestId}`
- **HTTP 상태 코드도 맞게**(200·201·204·400·401·403·404·409·429·500). 바깥 숫자 = 큰 분류(앱이 재로그인·재시도 결정), 안쪽 `error.code` = 세부 이유(화면 문구). FastAPI 기본 422 오류도 이 껍데기로 바꿈(400 `VALIDATION_ERROR`, 틀린 칸은 `details`)
- 오류 코드 표: 코드 → 뜻 → 상태 코드 → 화면 문구·Figma 예외 화면(I-01에서 I-12)
- 단위: 거리 m, 시간 초, 속도 km/h, 시각은 UTC ISO 8601(`Z` 붙임). 사용자 시간대는 프로필에(주간 목표 "설정일부터 7일")
- 목록은 커서 방식(`nextCursor`는 data 안). meta엔 화면에 안 쓰는 것만
- 판정은 서버: 인증 결과, 공식 기록 값(인증 완료 = 계기판, 미인증 = 센서), 레벨·인증 마크·주간 목표 집계
- 기록 업로드는 앱이 만든 ID로 같은 요청 두 번 와도 한 번만 저장(오프라인 달리기를 정하든 안 하든 API 안 바뀜)

## 결정된 것·미정 (11/06 민재)
- 몸무게 필드는 둔다. 속도 추정엔 안 쓰므로 용도를 개인정보처리방침·App Store 개인정보 항목에 적어야 함(심사 5.1.1)
- 미정: OCR을 서버에서 하는지(PRD 12.2와 모순) → 사진 올리기와 "앱이 읽은 값 올리기" 둘 다 자리만 / 오프라인 달리기 허용 여부
- 실사 영상 코스는 최하위 → 코스 종류 필드만 열어 둠

## 순서
1. 저장소 `docs/api/README.md`(공통 규칙·오류 코드 표) + 노션 API 표에 전체 줄 초안(화면 ID·백로그·유스케이스 연결, Figma는 전처럼 읽기만) → 상준(화면별 빠진 데이터·문구)·지환(인증·고스트·실시간) 검토
2. 검토 반영 → FastAPI 스텁(요청·응답 모델 + 고정 예시 응답 + 공통 껍데기·오류 처리) → `/docs` 링크를 노션 각 줄에, 상태를 "스텁"으로
3. 같은 예시 JSON을 Unity FakeApi가 사용(Normal·Empty·Error·지연 모드)

## 완료 기준
- 서버 데이터가 필요한 화면이 전부 API 한 줄 이상에 연결(화면 ID 칸으로 확인, 빈칸 0)
- PRD F01에서 F10 정책(인증 2상태, 공식 값, 주간 목표 주기, 레벨 임계값 등)이 응답 필드에 드러남
- 스텁이 뜨고 `/docs`에서 모든 API가 껍데기 모양 예시 응답·오류 응답을 돌려줌
- 상준·지환 확인
