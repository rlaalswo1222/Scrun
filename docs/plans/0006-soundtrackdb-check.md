# 계획 0006: 공개 데이터(SoundTrackDB)로 충격 + 걸음 수 공식을 여러 사람에게 확인

- 상태: **완료** (2026-10-28). 결과 [soundtrackdb.md](../speed/soundtrackdb.md)
- 데이터: [SoundTrackDB](https://github.com/Columbia-ICSL/SoundTrackDB) (Nie 외, "SoundTrack", IMWUT 2025, DOI 10.1145/3729486, MIT). 61명, 공공 헬스장 13곳, 363회. 러닝머신 계기판 위 폰의 가속도 x·y·z 100Hz, 정답 = 파일 이름의 설정 속도(5에서 10 mph, 정수)
- 왜: 우리 기록은 1명·러닝머신 1대. 다른 사람·다른 기계에서도 통하는지, 보정 구간이 몇 개면 되는지 근거가 없음

## 무엇을
1. 가속도 파일만 `data/external/soundtrackdb/imu_csv/`로 받음(약 950MB)
2. SpeedLab과 같은 방식으로 파일마다 충격 세기·걸음 수 계산(앞뒤 30초 버림, 20초 창 여러 개)
3. 같은 사람·같은 날 묶음(속도 3가지 이상)마다: 보정에 속도 1, 2, 3개를 쓰고 남은 속도 맞히기 → 오차 분포
   - 1개: 기울기는 다른 사람들 평균을 빌림(가설: 기울기는 사람 사이에 비슷)
   - 2개: 충격만 / 3개: 충격 + 걸음 수도
4. 결과: `docs/speed/soundtrackdb.md` + 스크립트 `speedlab/exp/soundtrackdb.py`

## 주의
- 100Hz라 우리(420Hz)보다 거침. 충격 값 자체는 우리 앱과 다름 → 공식의 "모양"과 보정 구간 수만 비교
- 속도를 바꾼 직후·걷기·8 km/h 아래 없음. 이 결과는 "다른 데이터에서 확인"이지 우리 앱 실측이 아님(보고서엔 출처와 함께)
