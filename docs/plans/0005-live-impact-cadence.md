- 상태: **구현** (2026-10-28). 에디터에서 식 확인(numpy 최소제곱과 같은 값), APK 빌드(20:17), 폰 확인 남음
- 작성: 2026-10-28, 사용자 승인
- 왜: 10/28 같은 기록을 PC에서 다시 계산하면 충격만 쓸 때 오차 크기 평균 약 0.43, 걸음 수까지 넣으면 약 0.28 km/h (4구간, 1명, 같은 날)

## 무엇을
1. 실시간 속도 = a + b·ln(충격) + c·spm. 달리기 보정 구간이 4개 이상일 때만, 모자라거나 충격과 걸음 수가 거의 같이 움직이면 지금처럼 충격만
2. `est.csv` 끝에 `imp_kmh`(충격만), `impcad_kmh`(충격 + 걸음 수) 두 열 추가 → 같은 기록으로 두 방법 비교
3. 보정 끝 메시지와 보정 표시에 지금 쓰는 식 표시
4. 확인: 같은 점으로 Unity와 numpy 계수가 같은지
