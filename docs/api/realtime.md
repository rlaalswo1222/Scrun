# 실시간 같이 뛰기 (WebSocket)

같은 코스(= 맵 하나)에 들어온 사람들이 서로의 위치를 주고받는 규칙. 결정은 [ADR-0010](../adr/0010-realtime-fastapi-websocket.md), 계획 [0029](../plans/0029-run-together-s3.md). 서버 코드 `backend/app/realtime/`, 앱 코드 `unity/TestRun/Assets/Scrun/App/Realtime/`.

## 붙기
1. `POST /v1/courses/{courseId}/entries`(맵 입장) 응답의 `realtime = {url, token}`
2. `url`로 WebSocket 연결(`wss://`, 로컬 개발은 `ws://`), 헤더 `Authorization: Bearer {token}`. 토큰은 **그 맵 하나에만**, 6시간. 다른 코스에 입장하면 앞 맵 토큰은 못 씀(4403). 주소(`?token=`)에 넣은 토큰은 받지 않는다(서버·프록시 접속 기록에 주소가 남음)
3. 붙자마자 서버가 `welcome`을 보낸다. 다시 붙어도 매번 `welcome`(방 상태를 통째로 다시 받음)
4. 붙은 뒤 **첫 `state`를 보내기 전에는 다른 사람에게 안 보인다**(앱은 섬 씬이 열려 입장 위치에 선 뒤부터 보냄 → 시작점 0m에 나타났다 순간이동하지 않음). 첫 `state`에서 다른 사람에게 `joined`

## 메시지 (JSON 텍스트, 필드 camelCase)
| 방향 | type | 필드 | 언제 |
|---|---|---|---|
| 폰 → 서버 | `state` | `d`(코스 시작점부터 m, 한 바퀴 안), `v`(km/h), `running`(bool) | 초당 2번(달리기 전에도: 연결 살아 있음 표시) |
| 폰 → 서버 | `ping` | `t`(폰 시각 ms, 그대로 돌아옴) | 5초마다(왕복 지연 실측·서버 시각 맞추기). 서버는 기다리지 않고 바로 `pong` |
| 폰 → 서버 | `leave` | 없음 | 맵을 나갈 때. 서버가 바로 `left`를 알리고 1000으로 닫음 |
| 서버 → 폰 | `welcome` | `you`, `mapInstanceId`, `courseLengthM`, `serverTime`(ms), `runners`[나 빼고 `{userId, nickname, d, v, running}`] | 붙을 때 |
| 서버 → 폰 | `states` | `serverTime`, `runners`[나 빼고 `{userId, d, v, running}`] | 초당 2번 |
| 서버 → 폰 | `joined` | `runner{userId, nickname, d, v, running}` | 새 사람이 첫 `state`를 보냄 |
| 서버 → 폰 | `left` | `userId` | `leave`, 끊긴 지 30초가 지남, 다른 맵으로 옮김 |
| 서버 → 폰 | `pong` | `t`(보낸 값), `serverTime` | `ping`에 답 |

- 서버는 `d`를 코스 길이로 나눈 나머지로, `v`를 0–30 km/h로 자른다. 숫자가 아니면(NaN 등) 닫는다(4400)
- 모르는 `type`은 무시한다(앱이 새 메시지를 먼저 보내도 끊기지 않게)
- 한 메시지는 1024자까지, 텍스트만(바이너리는 4400)

## 끊김
- 서버: 폰이 **10초** 동안 아무것도 안 보내면 닫는다(1001). 끊긴 사람은 **30초** 동안 방에 남기고(다른 폰엔 마지막 `d`·`v`로 계속 보임: 러닝머신은 계속 돌고 있다고 봄), 그 안에 다시 붙으면 `joined`·`left` 없이 이어진다. 일부러 나가는 건 `leave`(바로 빠짐)
- 앱: 맵을 나가면 `leave` → 닫기 인사 → 서버가 닫을 때까지 최대 2초 기다림. 다시 붙기 전에도 앞 소켓은 닫기 인사를 하고 버린다
- 앱: 서버에서 **5초** 동안 아무것도 안 오면 끊긴 것으로 보고 다시 붙는다. 다시 붙는 간격은 1·2·4·8초(그 뒤로는 8초마다)
- 닫는 코드가 4000번대면 다시 붙지 않는다

| 코드 | 뜻 | 앱이 할 일 |
|---|---|---|
| 1000 | `leave`를 받음 | (앱이 나간 것) |
| 1001 | 10초 동안 조용함 | 다시 붙기 |
| 4001 | 같은 계정이 다른 연결로 붙음 | 멈춤("다른 기기에서 접속") |
| 4400 | 모양이 틀린 메시지 | 멈춤(앱 버그, 기록 남김) |
| 4401 | 토큰 없음·틀림·만료 | 다시 입장해야 함 |
| 4403 | 이 맵에 자리가 없음(다른 코스로 옮김) | 다시 입장해야 함 |

## 인원
`runnersNow`와 입장 인원 검사는 "방에 붙어 있는 사람(끊긴 지 30초 안 포함) + 입장했지만 2분 안에 아직 안 붙은 사람"(`core/occupancy.py`). 어느 코스로 셀지는 자리(`course_entries`)가 정한다(앱이 꺼져 옛 방에 남은 사람도 옮긴 코스로 셈 → 목록·상세·입장 검사가 같은 수). 방 상태는 서버 메모리에만 있어서 서버를 다시 켜면 비고, 폰들이 다시 붙으면 채워진다.

## 입장 위치
그 맵에 붙어 있고 달리는 사람(`running=true`, 끊긴 사람 제외)이 있으면 한 명을 골라 20–40m 뒤, 없으면 코스 위 랜덤(BL-25 ②).

## 코스 길이
`d`는 섬 코스 위 거리라 서버 코스 길이(`courses.length_m`)와 섬 코스 길이가 같아야 한다. 서버 값은 섬과 같은 계산(`RoadNetwork.BuildRoute`)으로 잰 정수라 차이가 1m 안쪽(마이그레이션 `seed_courses`). 2m 넘게 다르면 앱이 경고를 남긴다(`AppRunBridge`). 새 맵이 나오면 서버 코스 길이도 같이 바꾼다.

## 앱에서 그리기
다른 사람 위치는 받은 `d`에서 `v × 지난 시간`만큼 앞으로 내다보고, 새 값이 오면 0.5초에 걸쳐 맞춘다(1차원·거의 일정한 속도라 지연 버퍼 대신, 가설 → 실측으로 확인).

## 시험용 가짜 러너
`backend/scripts/fake_runner.py`: 가짜 카카오 서버(로컬)에 가짜 계정으로 들어가 일정한 속도로 달리고, 들어옴·나감·왕복 지연을 찍는다. 에디터 하나로 "같은 맵의 다른 사람"을 볼 때, 여러 명 부하를 볼 때 쓴다.

