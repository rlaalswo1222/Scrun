러닝머신 함께 달리기

폰과 이어폰만으로 러닝머신 속도를 재고, 그 속도로 다른 러너들과 같은 코스를 함께 달리는 앱입니다. 핵심 기술은 속도 측정, 보여 주는 화면은 코스입니다.

1. 문제 정의

  • 러닝머신 달리기는 같은 자리에서 혼자 반복하는 운동이라 지루하고, 오래 이어 가기 어렵습니다.
  • 가상 코스를 함께 달리는 서비스가 있지만, 대부분 연동 러닝머신이나 별도 센서가 있어야 속도가 반영됩니다.
  • 헬스장의 일반 러닝머신은 속도를 밖으로 알려 주지 않습니다. 앱이 속도를 알려면 사용자가 이미 가진 폰과 이어폰의 센서로 추정해야 합니다.

2. 목표

속도 추정

별도 기기 없이 폰·이어폰만으로 러닝머신 속도를 정확하게 추정

함께 달리기

추정한 속도로 다른 러너와 같은 코스를 실시간으로 함께 달리는 화면

코스 선택

실사 영상 코스와 직접 만든 3D 맵 코스를 모두 제공하고 사용자가 선택

6. 속도 측정 방법

방식: 속도 = 걸음 수 × 보폭. 걸음 수는 센서 진동의 반복 주기로 세고, 보폭은 사용자가 정해진 속도로 몇 구간 뛰어서 맞춥니다(보폭 = a + b × 걸음 수).

구성센서상태
노트북 서버 + 실시간 분석 화면—완료 같은 와이파이에서 실시간 수신
갤럭시 웹 기록기가속도, 전면 카메라(머리 위치)완료 실측 진행
아이폰 앱가속도, 에어팟 머리 움직임작성 완료 맥 빌드 대기

해결한 문제 · 결정 사항

  • 거치대 폰에는 모터·벨트 떨림이 가장 세게 잡혀 걸음 신호를 덮었습니다. → 발이 벨트를 칠 때의 짧은 충격의 세기만 뽑아 박자를 세도록 바꿨고, 걸음 수가 안정적으로 잡히게 됐습니다.
  • 전면 카메라로 얼굴과 어깨를 인식하는 방식은 정확도가 좋지 않아 보류하기로 했습니다. 대신 에어팟의 센서(머리 움직임)를 활용해 정확도를 개선하기로 했습니다.

에어팟 센서로 얻는 정보와 기대 효과

거치대 폰은 러닝머신을 거쳐 전해진 진동을, 에어팟은 몸(머리)의 움직임을 직접 잽니다. 머리 가속도·회전 속도·방향을 받습니다.

보폭 단서

블라인드 테스트에서 서로 다른 속도의 걸음 수가 같게 나왔던 것처럼, 걸음 수만으로는 보폭 차이를 알 수 없습니다. 보폭이 크면 공중에 떠 있는 시간(머리가 자유낙하하는 구간)과 착지 충격·위아래 흔들림이 커지므로, 이를 걸음 수와 함께 써서 같은 걸음 수라도 속도를 구별하려 합니다.

오인식 차단

폰을 손으로 흔들거나 옆 러닝머신 진동이 잡혀도, 에어팟의 머리 박자와 맞지 않으면 걸러냅니다.

멈춤 감지

러닝머신 레일에 서 있으면 머리 움직임이 바로 사라져 멈춤을 알 수 있습니다.

9. 코스 화면

두 가지 방식을 비교했습니다. 실사 느낌과 3D 자유도(뒤 보기, 아바타 가림, 실시간 함께 뛰기)가 서로 맞바뀌는 관계입니다. 그래서 하나만 고르지 않고 두 방식을 모두 제공해 사용자가 선택하도록 하기로 했습니다.

방식실사 느낌3D 자유도결과
실사 영상 + 3D 복원
달리며 찍은 영상에서 카메라 경로를 복원하고 아바타를 합성		높음낮음코스 복원(일부 구간은 수동 보정)과 아바타 합성까지 완료. 영상 속 물체 뒤로 아바타가 가려지는 처리는 실패해서 보류.
직접 만든 3D (섬 원형 트랙)
실제 하늘 사진·사진 질감·나무 생성기·3D 풀잎		게임 수준완전맵을 직접 구현해 자유도는 높지만, 시연 시 실사 영상보다 퀄리티가 낮아 보일 수 있음.

실사 영상 + 3D 복원: 진행 방식

  1. 영상 확보: 몸에 단 액션캠으로 달리며 찍은 1인칭 영상. 화면에는 고화질, 계산에는 낮춘 화질을 씁니다.
  2. 카메라 경로 복원 (SfM, COLMAP): 프레임 사이의 같은 특징점을 찾아 프레임마다 카메라 위치·방향과 주변 3D 점을 계산합니다. 영상이 길어 여러 구간으로 나눠 복원한 뒤 이어 붙였고, 몸에 고정된 카메라라 렌즈 값은 고정했습니다.
  3. 복원 실패 구간 수동 보정: 특징점이 적어 경로가 끊긴 구간은 직접 만든 웹 도구에서 화면 속 발밑 경로를 찍어 채웠습니다.
  4. 거리–영상 시간 표: 복원한 경로로 "영상 몇 초 = 코스 몇 m" 표를 만들고, 사용자의 러닝머신 속도에 맞춰 영상 재생 속도를 바꿉니다.
  5. 아바타 합성: 러너마다 코스상 거리 → 땅 위 3D 위치로 바꾼 뒤, 그 프레임의 카메라 위치·방향으로 Three.js에서 그려 영상 위에 겹칩니다.
  6. 가림 처리 (보류): 깊이 추정 AI(Depth Anything V2)와 물체 분할 AI(SAM 2)로 아바타보다 가까운 사람·차 뒤에 아바타를 숨기려 했지만, 경계가 어긋나고 깜빡여서 보류했습니다.

10. 향후 계획

  1. 아이폰·에어팟 실측: 기록 앱을 빌드해 헬스장에서 아이폰·에어팟·갤럭시 동시 측정
  2. 정확도 개선: 에어팟 보조 지표를 더한 모델과 걸음 수만 쓴 모델의 오차 비교, 피험자 확대

  4. 함께 달리기: 러너 위치·속도 공유 서버 구현 후 여러 명 동시 달리기 시연
