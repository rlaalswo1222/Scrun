러너 아바타 모델 요청서

실제 러닝 영상 위에서 함께 달리는 3D 러너를, 지금의 회색 마네킹에서 러닝복을 입은 사람으로 바꾸려고 합니다. 이 문서는 모델을 만들 때 필요한 조건을 정리한 것입니다.

화면에서 어떻게 보이나

앱은 1인칭이라 화면에 나오는 러너는 대부분 내 앞에서 등을 보이며 달립니다. 배경은 맑은 날 해안 산책로 실사 영상이고, 주로 폰 화면으로 봅니다.

5~15m 앞화면 높이의 1/3 정도. 뒷머리, 셔츠 등판, 반바지, 종아리, 신발 밑창이 잘 보입니다.
15~50m 앞손가락 한 마디 크기. 실루엣과 옷 색만 구분됩니다.
얼굴거의 보이지 않습니다. 얼굴보다 뒷모습과 옷 질감에 시간을 써 주세요.

가장 중요한 것 지금 모델이 CG처럼 보이는 가장 큰 이유는 반짝이는 플라스틱 재질과 온몸이 한 가지 색인 점입니다. 천은 무광(거칠게), 피부와 옷은 색이 구분되게 해 주세요.

만들 것

사람 4명입니다. 각자 한 파일(.glb)에 동작 3개(서 있기, 걷기, 달리기)를 넣어 주세요. 셔츠 색은 앱 순위표의 러너 색과 맞춥니다.

나#E8590C · runner_me.glb3인칭 화면에서만 보임
민지#1C7ED6 · runner_minji.glb
준호#2F9E44 · runner_junho.glb
서연#AE3EC9 · runner_seoyeon.glb

셔츠는 따로 재질로 나누고 재질 이름을 TeamColor로 해 주세요. 앱이 이 재질의 색을 러너 색으로 바꿔서, 나중에 러너가 늘어도 같은 모델을 다른 색으로 쓸 수 있습니다. 셔츠 텍스처는 밝은 회색이나 흰색 바탕에 주름과 음영만 넣어 주세요.

기술 사양

앱은 웹(three.js)에서 돌아가고 폰에서 4명을 동시에 그립니다. 아래 조건이 맞지 않으면 모델이 안 보이거나, 크기가 틀리거나, 발이 땅에서 미끄러집니다.

항목조건
파일 형식glTF 2.0 Binary .glb, 텍스처를 파일 안에 포함사람 1명 = 파일 1개
크기와 방향1단위 = 1m, 키 1.65~1.80m, 원점은 두 발 사이 바닥, Y축이 위, 정면이 +ZMixamo에서 받은 그대로 내보내면 맞습니다. cm 단위로 나오면 100배 커집니다
뼈대Mixamo 표준 뼈대, 뼈 이름 그대로 (mixamorig:Hips, mixamorig:LeftFoot, mixamorig:RightFoot …)앱이 발 뼈 이름으로 걸음 속도를 재서 발 미끄러짐을 막습니다
동작이름을 정확히 idle, walk, run으로. 세 동작 모두 제자리(In Place), 끊김 없이 반복앞으로 나아가는 건 앱이 합니다. 동작이 몸을 앞으로 옮기면 러너가 튑니다
폴리곤삼각형 15,000~30,000개지금 모델은 49,000개. 폰에서 4명 + 영상 재생을 버티려면 줄여야 합니다
재질3개 이하 (피부, 옷, TeamColor 셔츠). PBR(metallic-roughness), metallic 0, 천은 roughness 0.7~0.9
텍스처1024×1024 (최대 2048), Base Color + Normal 필수, ORM은 선택, JPG/PNG
머리카락메시로 만들거나, 투명을 쓰면 Alpha Mode = MASKBLEND는 웹에서 그리는 순서가 꼬여 깜빡입니다
스키닝정점당 뼈 영향 4개 이하, 뼈 70개 이하
파일 용량1명당 8MB 이하

추천 작업 순서

  1. 모델링 Blender로 러닝복 차림의 사람을 만듭니다(반팔 셔츠, 러닝 반바지나 레깅스, 러닝화). 캐릭터 제작 도구나 구매한 에셋으로 시작해도 되지만, 학교 프로젝트와 앱 시연에 써도 되는 라이선스인지 확인해 주세요.
  2. 뼈대와 동작 mixamo.com(Adobe 계정으로 무료)에 올려 자동으로 뼈대를 넣습니다. 그다음 Idle, Walking, Running 동작을 In Place 체크를 켜고 FBX(With Skin)로 받습니다.
  3. 합치기 Blender에서 세 동작을 한 모델에 모으고, 동작(Action) 이름을 idle / walk / run으로 바꿉니다.
  4. 내보내기 File → Export → glTF 2.0, 형식은 glTF Binary, +Y Up 켜기, Animation 포함, 모디파이어 적용.
  5. 확인 gltf-viewer.donmccurdy.com에 끌어다 놓고, 동작 3개가 보이는지와 반복할 때 끊기지 않는지 봅니다.

넘기기 전 체크리스트

  • 파일 4개: runner_me.glb, runner_minji.glb, runner_junho.glb, runner_seoyeon.glb
  • 각 파일에 동작 idle, walk, run이 있고 전부 제자리 동작
  • 키가 1.65~1.80m (뷰어 격자 기준), 정면이 +Z
  • 셔츠 재질 이름이 TeamColor
  • 삼각형 30,000개 이하, 파일 8MB 이하
  • 뒷모습 스크린샷 1장씩 (등판, 뒷머리, 신발 밑창이 보이게)

피해 주세요

  • 광택 있는 재질, 온몸이 한 색인 디자인
  • 앞으로 이동하는 동작 (In Place 안 켠 Running)
  • cm 단위로 내보내서 100배 커진 모델
  • 반투명(BLEND) 머리카락이나 옷
  • 브랜드 로고 (실제 브랜드 상표)
참고용으로 지금 쓰는 모델(run3d/assets/Xbot.glb, Mixamo 뼈대 67개, 삼각형 49,112개)을 같이 넘겨드리면 크기, 방향, 동작 이름을 그대로 맞춰 볼 수 있습니다. 파일을 받으면 개발 쪽에서 TeamColor 색 바꾸기와 사람별 모델 연결을 붙입니다.
