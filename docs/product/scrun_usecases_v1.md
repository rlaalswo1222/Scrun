## UC09 혼자 달리기

- 사전조건: 로그인됨, 동작 센서 권한 있음, 폰 거치됨
- 사후조건: 기록이 "인증 대기"로 저장됨
- 기본 흐름
  1. 러너가 [달리기 시작]을 누르고 코스와 함께 달릴 상대를 고른다.
  2. 시스템이 센서 상태를 확인하고 "걷기 시작하세요"를 보여 준다. 보정된 적이 없으면 러닝머신 표시 속도를 한 번 입력받는다(1점 보정).
  3. 러너가 러닝머신 위에서 걷기 시작한다.
  4. 시스템이 걸음을 감지하면 카운트다운 후 자동 시작한다.
  5. 시스템이 걸음으로 속도를 추정하고, 아바타가 코스를 달리며 페이스·거리·시간을 보여 준다.
  6. 러너가 코스를 완주하거나 [종료]를 누른다.
  7. 시스템이 결과를 보여 주고 기록을 저장한 뒤 UC13을 권한다.
- 대안 흐름
  - 2a. 센서 신호 비정상 → [다시 연결] / [폰 진동만으로 계속]
  - 5a. 걸음이 몇 초 넘게 멈춤 → 자동 일시정지, 다시 걸으면 이어서
  - 5b. 에어팟 연결 끊김 → 폰 진동으로 바로 전환, 알림
  - 5c. 전화·앱이 뒤로 감 → 일시정지, 돌아오면 [이어서 달리기]
  - 6a. 1분 미만 → 저장하지 않음
- 관련 요구사항: R03, R04, R05, R12, R14

## UC13 계기판 인증받기

- 사전조건: UC09가 끝나 기록이 "인증 대기", 촬영 시한 안
- 사후조건: 기록이 "인증됨" 또는 "미인증"으로 확정, 인증됐으면 보정·보상 갱신
- 기본 흐름
  1. 러너가 [계기판 찍고 인증받기]를 누른다.
  2. 시스템이 앱 안 카메라와 계기판 위치 틀을 보여 준다.
  3. 러너가 계기판을 찍는다.
  4. 서버가 사진에서 거리·시간을 읽는다.
  5. 서버가 촬영 시한·허용 오차·사진 중복을 검사해 "인증됨"으로 판정한다.
  6. 시스템이 계기판 값으로 보폭 보정을 갱신한다(포함).
  7. 서버가 연속 일수·배지·체형 점수를 계산하고(포함), 새 보상이 있으면 보여 준다.
- 대안 흐름
  - 1a. [인증 없이 저장] → 미인증. 시한 안이면 UC14로 나중에 인증
  - 3a. 카메라 권한 없음 → 요청, 거부 시 미인증
  - 4a. 숫자를 못 읽음 → 다시 찍기, 몇 번 실패하면 미인증
  - 5a. 기록과 차이 큼 → "계기판 값으로 고치고 인증할까요?" 고치면 인증, 그대로면 미인증
  - 4b. 인터넷 없음 → 사진을 기기에 보관, 연결되면 판정·알림
- 관련 요구사항: R05, R06, R07, R08, R09, R15
