# 러닝머신 계기판 사진 숫자 읽기(OCR) — 첫 시험 (2026-10-29)

달린 뒤 계기판 결과를 찍어 거리·시간을 읽는 기능(인증)의 가능성 확인. 조건: **폰 안에서 무료로**(사진마다 돈 드는 LLM API는 제외, 10/29 민재 결정).

## 시험 조건
- 사진 2장: 10/29 04:32, 갤럭시 S22로 손에 들고 정면, 같은 러닝머신(빨간 LED 7세그먼트, 칸마다 라벨: 경사도·거리·시간·칼로리·심박수·속도). 두 장 모두 같은 화면: 0.0 / 0.13 km / 1.00(1분) / 9 / StoP / 0.0
- 사진은 저장소에 안 올림(커버 유리에 찍는 사람이 비침). 숫자 칸 6개를 켜진 빨간 LED로 자동으로 찾아 잘라 칸마다 읽음, 채점은 심박수 칸 뺀 5칸 × 2장 = 10칸
- 도구: Windows 기본 OCR(`speedlab/ocr/winocr.ps1`), Docker 안 ssocr 2.22.1 + Tesseract 5(eng, 7세그먼트 학습 파일 ssd·7seg — [Shreeshrii/tessdata_ssd](https://github.com/Shreeshrii/tessdata_ssd), 합성 글꼴로 학습한 시험판), `speedlab/ocr/Dockerfile`

## 결과 (10칸 중 숫자가 맞은 칸, 소수점·콜론은 무시)
| 방법 | 맞음 |
|---|---|
| Windows OCR, 사진 그대로 / 칸별로 잘라 흑백 | 0 / 0 ("EHE19", "5&oP" 등) |
| Tesseract eng | 0에서 1 |
| ssocr ([7세그먼트 전용](https://www.unix-ag.uni-kl.de/~auerswal/ssocr/)), 여러 기준·기울기 보정 | 0에서 2 |
| Tesseract ssd·7seg + 고정 밝기 기준(하얗게 빛나는 중심) | 3에서 4 (한 장은 기준에 안 걸려 0) |
| **Tesseract ssd·7seg + 칸마다 밝은 상위 10%** | **5** (필요한 거리·시간 4칸 중 3칸) |

- Otsu(자동 이진화)는 꺼진 "888" 획까지 켜진 것으로 잡아 나빠짐
- 인쇄된 라벨("시간", "km", "kcal", "km/h")은 Windows OCR이 제대로 읽음 → 칸의 뜻은 라벨로 정할 수 있음

## 판단 (가설 포함)
- **일반 OCR은 7세그먼트를 못 읽음**(0/10). 7세그먼트 학습 파일을 쓴 Tesseract가 가장 나았지만 절반 수준
- **병목은 인식기보다 전처리(노출)**: 4초 차이로 찍은 두 장 중 한 장은 같은 기준에서 숫자가 다 지워짐. LED가 하얗게 타고, 꺼진 획이 비치고, 숫자가 기울어짐
- 2장·같은 화면이라 **실패율은 아직 말할 수 없음**
