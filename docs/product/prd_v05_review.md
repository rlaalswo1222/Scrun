## 정리
### 사실이 틀린 것
1. 12.1 속도 수치: PRD "10월 5% 미만" ↔ 같은 날 3.5%, 같은 날 블라인드 +5.3%. PRD "10/29 달리기 0.29·걷기 0.25·반영 5~6초" ↔ [live_iphone.md](../speed/live_iphone.md) 달리기 0.16(에어팟 포함)·0.12(폰만), 걷기 0.29, 따라오기 그림상 5에서 10초. 0.25·"5~6초"는 기록에 없음(출처 확인). 다른 날 S22 0.52(+0.51 치우침)도 같이 적어야 함
2. OCR 위치 모순: F06·BL-17 "서버 OCR 확정" ↔ 12.2·BL-6 "Vision OCR 네이티브 플러그인". 제안: 카메라 노출 제어는 네이티브, 판독은 서버. (11/06 민재: 미정)
3. 키·몸무게 필수(6.2, UC-01, BL-1): 속도 추정에 안 씀 → 심사 5.1.1. BL-1 스토리 "Apple로 로그인"·"그래야 내 속도를 보정" 문구 틀림. (11/06 민재: 몸무게 필드는 둠, 용도 명시)
4. Canvas Scaler(12.2, BL-41)는 uGUI → UI Toolkit은 PanelSettings Scale With Screen Size(393×852)

### 이미 정한 방향과 부딪히는 것
