# 속도 추정에 쓸 만한 공개 데이터 (2026-10-29 조사)

웹 조사만 함, 데이터 본 파일은 안 받음. 내용은 각 논문·저장소 페이지에서 확인한 것이고 "미확인"은 못 본 것. 수치는 논문이 보고한 값이며 우리 실측이 아님. 이미 쓰는 SoundTrackDB는 [soundtrackdb.md](../speed/soundtrackdb.md).

**큰 빈 곳:** 계기판 위 폰(또는 러닝머신 프레임 센서) + 설정 속도를 공개한 데이터는 SoundTrackDB뿐. 러닝머신 기종마다 계기판까지 진동이 어떻게 전해지는지는 공개 데이터로 못 채움 → 우리가 여러 기종에서 직접 모아야 함. 아래는 모두 "몸의 움직임 ↔ 속도" 관계를 빌려 오는 용도.

### 4. 같은 속도에서 걸음 수만 바꾼 기록 (걸음 수와 충격이 속도와 따로 움직이나)

### 6. 러닝머신 쪽 근거
- Willwacher 외, Sci Rep 2021 11:2244: 착지 때 벨트가 순간 느려지는 정도가 체중·속도·기종에 따라 다름(대부분 목표 속도의 2에서 10%, 낡은 벨트 12에서 25%). 러닝머신 4대, 7명. 요약값만 공개. 사람·기종마다 충격 기울기가 다른 이유 후보(가설)

- VibRun(IMWUT 2025): 러닝머신 프레임 IMU, 17명, 3기종. 우리와 가장 비슷한 설정
- Yuan 외, Front Bioeng Biotechnol 2026: Xsens 17개(머리 포함), 25명, 8·10·12 km/h 각 3분

- Patoz 외 2022: 100명 넘게, 9·11·13 km/h
