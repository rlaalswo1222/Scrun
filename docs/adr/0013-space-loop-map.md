# ADR-0013: 3D 루프 코스는 가상 섬 대신 "우주 루프"로 만든다

- 상태: 제안 (11/11 상준 초안, 11/21 PR에서 민재·지환 확인)
- 날짜: 2026-11-11 (저장소 반입 2026-11-21, 계획 0063)
- 결정한 사람: 상준(맵 방향·코스 기획 담당). 팀 합의는 이 PR 리뷰로

## 배경
11/07 결정으로 기존 섬 맵(Island01)을 임시로 쓰고 있었다. 11/11 상준이 앱 디자인을 우주 컨셉으로 바꾸면서(Figma "스크런 우주 디자인"), 맵도 같은 세계로 맞춰야 했다. 로고의 행성 5개가 맵의 5구간이 되고, 홈·코스 시안(계획 0062)도 이미 "3km 우주 루프, 구간 5개"를 그리고 있다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| A. 섬 맵(Island01) 유지 | 이미 동작, 아이폰 성능 측정된 맵 | 우주 디자인과 세계가 다름, 시안의 "구간 5개"를 보여 줄 수 없음 |
| B. 강변 공원(11/10 Blender 목업) | 실제 러닝과 닮음 | 실제 장소처럼 보여 "지명 창작" 규칙과 부딪힘, 우주 디자인과 다름 |
| C. **우주 루프** (구간 5개 x 600m) | 디자인·로고·홈 시안과 같은 세계, 구간마다 다른 풍경이라 달리는 리듬이 생김 | 새로 만들어야 할 에셋이 많음, 아이폰 성능 미측정 |

## 결정
C. 3km 루프 하나를 5구간(구름 위 기지, 화성 협곡, 밤 숲 호수, 얼음 위성, 달 기지)으로 나눈다. 같은 트랙 키트(회색 패널 길, 파란 LED, 화살표, 가드레일)를 모든 구간이 공유하고, 경계 100m에서 땅·하늘·조명·안개가 섞인다. 사람마다 시작 구간이 다를 수 있다. 달리는 길은 평지(경사 안내 없음)를 유지한다.

## 이유
- 레퍼런스 5장(상준)이 모두 같은 트랙 키트를 써서 "공통 길 + 구간마다 다른 행성" 구조가 분명하고, 실제 장소가 아니라 지명 창작 규칙과도 맞는다
- 구간마다 지나가는 랜드마크(아치·터널·다리·게이트)가 달리는 리듬을 만든다
- 앱 화면(홈·코스·러닝 HUD 미니맵)이 이미 "구간 5개"를 기준으로 그려져 있다

## 결과와 위험
- **지킬 것**: 실제 행성·우주선을 본뜨지 않는다(지구·토성·아폴로 착륙선 모양 금지, 색·모양 창작). 한 번에 지금 구간 + 이웃만 켠다(`SpaceLoopStreamer`). 렌더 전용 효과(볼륨 안개, 절차 질감)는 Unity에서 안개 셰이더·후처리·입자로 대신한다
- **아이폰 성능**: 아이폰 15(11/21)에서 앱 설정(Medium·30fps)으로 5구간 모두 30fps, 60fps로 풀어도 60fps, 그리기 호출 60–110(아바타 20명 142), 6분 발열 보통(`docs/unity/space_loop.md` "아이폰 실측"). 메모리 4GB 폰·30분 연속은 아직. 줄여야 하면 하늘 셰이더부터
- **큰 파일은 저장소 밖**: 메쉬두 모델·텍스처와 구간 메시(약 147MB)는 GitHub Release의 zip으로 받는다(`unity/tools/spaceloop_fetch.py`, Poly Haven과 같은 방식). git에는 `.meta`·재질·목록만 둔다
- **메쉬두 이용 조건**: 키트 49종은 GPT 이미지 → 메쉬두 Image to 3D로 만들었다. 상준 말로 유료(프리미엄) 플랜이고, 메쉬두 도움말 기준 유료 플랜 결과물은 만든 사람이 소유한다(이용약관 원문은 11/16에 접속이 막혀 못 읽음, 커뮤니티 공개 여부는 상준 확인 필요)
- **바꿔야 할 문서**: 승인되면 `CLAUDE.md` "이미 정한 방향"의 "가상 섬, 손그림풍" 문구와 `docs/unity/unity_map.md`의 섬 맵 기준을 고친다. 실사 영상 코스(노션 "지구에서 달리기")는 이 ADR 범위 밖이다
- 다시 검토할 조건: 아이폰에서 줄여도 목표 fps가 안 나올 때, 에셋 제작이 12/11 발표 일정에 못 맞출 때
