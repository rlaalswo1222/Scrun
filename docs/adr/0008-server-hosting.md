# ADR-0008: 서버는 오라클 무료 서버에 Docker Compose(FastAPI + PostgreSQL)로 올린다

- 상태: 제안 (11/06 민재 인수인계에서 옮김, 서버 뼈대 만들 때 확정)
- 날짜: 2026-11-06
- 결정한 사람: 김민재 (제안)

## 배경
서버는 FastAPI로 정했다(ADR-0002). 이제 어디에 어떻게 올릴지, DB와 사진·기록 파일을 어디 둘지, 어떻게 테스트할지 정해야 한다. 목표는 12/11 최종 발표지만 기준은 출시 가능한 완성도. 학교 재료비 규칙상 쓴 만큼 나중에 청구되는 결제는 맞지 않는다(결제 직후 카드 삭제, 실제 금액이 계획 금액보다 크면 지원 불가).

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| 오라클 무료 서버 + Docker Compose | 돈이 안 듦, 서버 전체를 직접 제어, 로컬과 같은 구성 | ARM 인스턴스는 "용량 없음"으로 안 잡힐 수 있음, AMD 무료는 메모리 1GB라 빠듯, 유휴 회수 있음(PAYG 전환으로 막기) |
| 선불 VPS 1개월 (국내 가상서버, 크레딧 선충전 해외 VPS) | 안정적, 재료비 규칙에 맞게 결제 가능 | 재료비 남은 돈(약 23만원, 에셋이 우선)을 씀, 학교 돈은 12월 중순까지만 |
| 후불 클라우드(AWS·GCP 등) | 자료 많음, 관리형 DB | 카드를 계정에 계속 달아 둬야 해서 재료비 규칙과 충돌 |

## 결정 (제안)
오라클 무료 서버에 Docker Compose로 FastAPI + PostgreSQL을 올린다. 막히면 선불 VPS 1개월로 바꾼다(월구독 결제 마감 11/20 17시 전에 판단).

## 세부
- PAYG 전환으로 유휴 정지 방지. 전환 전에 무료 한도 확인
- 매일 DB 덤프를 서버 밖에 보관
- 사진·속도 기록 전체는 오라클 Object Storage를 S3 호환(boto3)으로
- 접속 정보는 환경 변수(공개 저장소에 올리지 않음)
- 테스트: FastAPI `/docs`로 눌러 보기 → pytest(정상·잘못된 값·로그인 없음·남의 기록, 카카오 확인은 가짜로, 테스트 DB 따로) → GitHub Actions로 PR마다 자동
- 백로그 후보: 앱 오류 수집(Sentry 등)

## 결과와 위험
- 학교 돈으로는 12월 중순까지만 덮인다. 출시 뒤 서버비는 팀이 낸다
- 실시간 "같이 뛰는 방"은 2주차 하루 스파이크로 FastAPI WebSocket vs Photon을 정한다(ADR-0002 위험 항목) → 그때 ADR 추가
- 다시 검토할 조건: 오라클 무료 인스턴스를 못 잡거나 1GB에서 성능이 안 나올 때
