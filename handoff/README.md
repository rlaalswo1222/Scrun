# 사람별 인수인계

각자 Claude와 이어서 작업하기 위한 **개인 메모**. 한 파일에 섞이지 않게 사람마다 따로 쓴다.

- 파일 이름: `handoff/<git user.name>.md` (`git config user.name`으로 확인. 예: `minjae.md`)
- 자기 파일만 고친다. 남의 파일은 읽기만
- 담는 것: 지금 하던 일, 다음에 할 일, 막힌 것. 짧게
- 팀이 함께 알아야 할 결론은 여기 말고 공용 문서에: 속도 `docs/speed/README.md`, Unity `docs/unity/unity_map.md`, 결정 `docs/adr/`, 계획 `docs/plans/`
- 처음이면 `minjae.md`의 모양을 참고해 자기 파일을 만든다
